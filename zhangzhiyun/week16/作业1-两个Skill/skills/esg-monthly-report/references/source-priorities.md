# ESG 信息源分级与检索模板

## 一、来源可信度分级（打分时的"权威性"维度）

| 级别 | 典型来源 | 用途 | 备注 |
|---|---|---|---|
| A（5分） | 国务院/国资委/证监会/生态环境部官网、上交所/深交所/港交所、中证指数、中国上市公司协会、客户官网、央企采购平台 | 政策原文、评级方法、客户事实、招标公告 | 可直接引用 |
| B（4分） | 新华财经、中国证券报、中国能源报、中国能源新闻网、澎湃、财新、中国经济新闻网 | 权威解读、行业数据转述 | 引用时保留媒体名与作者/日期 |
| C（3分） | 中国煤炭市场网(CCTD)、北极星、IESPlaza、行业学会公众号 | 细分行业数据、案例线索 | 数字需回溯原始报告 |
| D（2分） | 网易号/搜狐号/个人公众号、聚合站 | 线索发现 | 须回溯到 A/B 级来源后才能进证据表 |

## 二、政策/评级/标准常用检索入口

- 中证指数：`site:csindex.com.cn ESG 评价方法 V4.0`、公告页与 PDF 原文
- 交易所可持续发展披露指引：`上交所 可持续发展报告 指引 ESG`
- 国资委：`site:sasac.gov.cn 绿色低碳 供应链 指引`、`中央企业 社会责任 ESG`
- 中国连锁经营协会/行业协会团体标准：`ESG 评价规范 团体标准 发布`
- COP/国际规则：`COP31 气候行动 成果集`、`CBAM 2026 实施 碳足迹`
- 蓝皮书：`中国 ESG 投资发展报告 <年份>`、`煤炭行业社会责任蓝皮书 <年份>`

## 三、客户/行业检索模板

```
<客户> ESG <YYYY年M月>
<客户> 可持续发展报告 <年份>
<客户> 评级 AAA AA Wind ESG <年份>
<客户> 绿色供应链 / 碳管理平台 / CCUS / 矿区生态修复 <年份>
<行业> ESG 最佳实践 <年份>
<行业> 社会责任 蓝皮书 <年份>
<行业> 智能煤矿 / 绿电 / 固废资源化 <YYYY年M月>
<对标1> ESG 评级 <年份>   （逐个对标企业）
```

检索词需同时准备"ESG / 可持续发展 / 社会责任 / 双碳 / 绿色低碳"五组同义词；中文检索无结果时改用英文 `<company> sustainability report <year>`。

## 四、证据筛选的硬规则

1. **时间**：报告窗口内才叫"本月动态"；窗口外事实放入"存量基线"，并写明实际日期。
2. **主体**：新闻涉及的主体必须明确；"某公司"式匿名信息不进证据表。
3. **数字**：金额写清币种与单位（元/万元/亿元）；比例写清分母；排名写清榜单范围与机构。
4. **评级**：MSCI / Wind / 秩鼎 / 伦交所 / 中证的等级体系不同，禁止写成"评级为A，高于同行"而不点名机构。
5. **奖项**：获奖属于第三方评价，不等于实质 ESG 绩效；表述用"获XX奖项/入选XX名单"，不写"ESG表现行业第一"，除非有同口径排名来源。
6. **冲突**：同一事实两来源不一致时并列呈现；日期/数值冲突优先采信官方原文。
7. **缺失**：检索不到就明写"未检索到"，不用模型常识补全。

## 五、常见陷阱

- 搜索结果里的"发布日期"可能是转载日期而非事件发生日期，需读正文确认。
- 聚合站把多篇文章拼成一页，容易把 A 公司数据安到 B 公司；只引用明确标注主体的段落。
- "本月"跨年时（如 12 月→1 月）注意年份切换，检索式里两个年份都要跑。
- 微信公号文章常被搜索引擎截断，关键数字要回到正文核对。
