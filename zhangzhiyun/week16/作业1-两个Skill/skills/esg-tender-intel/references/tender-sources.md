# ESG 招投标数据源与监控入口

## 一、官方源（A 级，优先引用）

| 平台 | 入口 | 适用 |
|---|---|---|
| 中国政府采购网 | ccgp.gov.cn，"中标公告/竞争性磋商公告" | ESG咨询、碳核查、平台建设、评价服务 |
| 全国公共资源交易平台 | deal.ggzy.gov.cn | 园区EPC、工程建设、地方项目 |
| 央企采购平台 | 国家电网电子商务平台、南方电网供应链统一服务平台、国能e购、中招联合、华润守正 | 央企ESG报告/评级/能碳平台 |
| 企业官网采购/披露页 | 如上海机场集团采购公示、中国太平集中采购门户 | 上市公司ESG咨询中标 |
| 地方公共资源交易中心 | 各省/市交易中心网站 | 零碳园区、绿色工厂、区域碳平台 |

## 二、行业与第三方源（B/C 级，需回溯）

| 来源 | 用途 | 注意 |
|---|---|---|
| 北极星碳管家网、中国能源新闻网 | 项目线索、政策解读 | 追踪到原始公告 |
| IESPlaza 综合能源服务网 | 零碳园区申报服务统计 | 统计样本与口径要写明 |
| 乙方宝、知了标讯等标讯聚合站 | 发现公告 | 常截断金额与联系方式 |
| 行业公众号（"双碳招标月报"类） | 汇总样本（如"336份标书""437个项目"） | 属二手统计，不能与逐条明细相加 |

## 三、每日监控检索式（可直接复用）

```
昨日 ESG 报告编制 中标公告
昨日 零碳园区 招标 公告
site:ccgp.gov.cn ESG 中标
site:ccgp.gov.cn 碳足迹 中标
site:ccgp.gov.cn 能碳 平台 招标
"碳核查" 中标 公告 <日期>
"绿色工厂" 中标 <日期>
"<重点业主名单>" ESG 招标 <日期>
```

监控策略：
1. 每个工作日 09:00 执行；过滤发布日期 = 前一自然日（周一补周末）。
2. 与历史项目指纹库比对去重。
3. 评分 ≥ 14 且金额 ≥ 10 万元（或业主为央企/上市公司）才进入推送。
4. 无新增时也要推送"今日无新增"，避免静默失败。
5. 保留 `runs/YYYY-MM-DD.json` 日志，便于复核与补推。

## 四、可信度与交叉验证

- 金额必须来自公告原文；聚合站金额仅作线索。
- 中标方名称以公告为准，注意"联合体"需完整记录。
- 项目状态变化（招标→中标→流标）要更新历史库，不删除原记录。
- 第三方统计的"市场规模"与逐条公告的"中标金额合计"是两套口径，报告中分开展示。
