## 三、金额分档（统计口径）

| 档位 | 区间（万元） | 说明 |
|---|---|---|
| S1 | < 10 | 单产品碳足迹核查、小型认证、碳培训 |
| S2 | 10-50 | 绿色工厂申报、省级零碳园区申报、企业级碳核查 |
| S3 | 50-100 | 零碳园区申报咨询、ESG报告编制、碳管理平台模块 |
| S4 | 100-500 | 国家级零碳园区申报、能碳平台、ESG体系优化、区域碳核查 |
| S5 | > 500 | 省级碳市场建设、区域双碳公共服务平台、零碳园区EPC（亿元级） |

**硬规则**：EPC 亿元级项目与咨询几十万项目不得计算统一平均值；必须分档或分赛道统计。

## 四、去重规则

1. 标题核心词：去标点、去"项目/服务/采购/公告"等通用词，保留主体与赛道词。
2. 指纹 = `业主 + 标题核心词 + 金额(万元)`；无金额时用 `业主 + 标题核心词 + 日期月份`。
3. 同一项目的不同阶段：保留中标/成交阶段作为金额样本，招标阶段计入需求热度样本。
4. 字符 Jaccard ≥ 0.8 视为重复；保留来源级别更高、字段更完整的一条。

## 五、统计输出格式

| 维度 | 必出指标 |
|---|---|
| 热度 | 招标数、中标数、按月/季度趋势 |
| 赛道 | 项目数、中标金额合计、金额中位数、典型项目 |
| 金额 | 五档项目数与占比（分母=有金额的中标项目数） |
| 区域 | 项目数排名前 5 省份/区域 |
| 主体 | 业主类型占比、头部中标方 TOP5 |
| 局限 | 样本量、检索缺口、口径差异 |
