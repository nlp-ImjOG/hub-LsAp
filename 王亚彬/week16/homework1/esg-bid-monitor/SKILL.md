# ESG 投标信息汇总与监控

两种模式，根据用户意图选择。

## 模式 A：历史中标汇总

### 输入
- 时间范围（默认：过去 2 年）
- 主题（默认：ESG / 可持续发展 / 双碳）

### 工作流
1. 搜索近 2 年相关中标公告，关键词组合：
   - `ESG 咨询 中标 公告 {年份}`
   - `双碳 服务 中标结果 {年份}`
   - `可持续发展 报告编制 中标 {年份}`
   - `碳足迹 碳核算 中标 公告 {年份}`
   - `绿色低碳 规划 中标 金额 {年份}`
2. 从每条公告提取：项目名称、地区、中标单位、中标金额、日期、服务内容、链接
3. 统计：
   - 按服务类型分类（咨询规划 / 报告编制 / 碳核算碳审计 / 评价认证 / 技术服务）
   - 金额分布（<50万 / 50-100万 / 100-300万 / >300万）
   - 高频采购方类型、高频中标机构
4. 输出明细表 + 统计表 + 分析结论

### 输出格式
```markdown
# ESG / 双碳中标信息汇总（{START} ~ {END}）

> 样本：{N} 条公开中标公告　|　来源：政府采购网、公共资源交易中心、企业采购平台

## 一、中标明细
| 日期 | 项目名称 | 地区 | 中标单位 | 金额(万元) | 类型 | 来源 |
|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | ... | [链接](...) |

## 二、统计分析
### 2.1 按服务类型
### 2.2 按金额区间
### 2.3 关键发现（3-5 条）

## 三、热点招标方向
（基于样本归纳，每条注明依据哪几条数据）
```

## 模式 B：每日新招标监控

### 触发
"今天有什么ESG招标" / "推送今日新招标" / 定时调用

### 工作流
1. 搜索**当日或近 3 日**发布的相关招标公告（注意是"招标"不是"中标"）
2. 关键词：`ESG 招标 {今日}`、`双碳 采购 公告`、`碳核算 招标 最新`、`绿色低碳 招标公告`
3. 提取：项目名称、采购方、地区、预算、报名截止日、链接
4. 按截止时间排序，标注紧急程度

### 输出格式
```markdown
# ESG 招标日报 · {今日日期}

> 检索到 {N} 条新招标

| 项目名称 | 采购方 | 地区 | 预算 | 截止日 | 紧急度 | 链接 |
|---|---|---|---|---|---|---|
| ... | ... | ... | ... | ... | {高/中/低} | [链接](...) |

## 重点推荐
（挑 2-3 条最相关的，说明理由）
```

## 硬性约束

1. 金额必须从公告原文提取，**不许估算或编造**；公告未披露写"未披露"
2. 每条必须带来源链接和发布日期
3. 统计只基于实际搜到的样本，**明确标注样本量和局限**（公开渠道样本，非全量市场）
4. 搜索不到就写"未检索到"，不许编造
5. 日期严格按时间范围过滤

## 自检清单

- [ ] 每条都有链接、日期、金额（或"未披露"）
- [ ] 统计数字与明细表一致
- [ ] 标注了样本量和数据局限
- [ ] 没有编造的招标项目
