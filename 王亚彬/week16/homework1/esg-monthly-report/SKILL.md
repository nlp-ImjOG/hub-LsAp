# ESG 月报生成器

给定一个公司和目标月份，搜索互联网，生成结构化的 ESG 月报。

## 输入

- 公司名（默认：中国神华）
- 目标月份（默认：当前月份的上一个月）

## 工作流

### 1. 确定时间窗口
计算目标月份的 1 日和月末，记为 [START, END]。所有入选信息必须落在此窗口内；窗口外的一律丢弃。

### 2. 三路并行搜索
用搜索工具对以下三路各执行至少 2-3 组关键词：

**路 A：政策 / 评级 / 标准动态**
- `{年份}年{月份} ESG 政策 新规`
- `证监会 ESG 信息披露 标准 {年份}`
- `可持续发展 评级 标准 最新`

**路 B：行业动态与最佳实践**
- `{行业} ESG 最佳实践 {年份}`
- `{行业} 绿色转型 碳中和 动态 {月份}`
- `{行业} 绿色矿山 智能化 案例`

**路 C：公司动态与对标**
- `{公司} ESG {年份} 可持续发展`
- `{公司} 碳减排 治理 动态 {月份}`
- `{对标企业1} {对标企业2} ESG 评级 行动`

煤炭能源行业对标企业默认：中煤能源、兖矿能源、陕西煤业。

### 3. 筛选规则
- **时间**：发布日期在 [START, END] 内优先；窗口外但极其重要的可放"背景补充"，需标注日期
- **来源权威性**：政府网站 (gov.cn)、交易所、主流财经媒体（新华社、证券网、人民日报）、企业官网 > 自媒体
- **相关性**：必须直接涉及 ESG / 可持续发展 / 双碳 / 碳减排 / 绿色转型，泛泛的环保新闻不要
- **去重**：同一事件多家报道只留来源最权威的一条

### 4. 输出格式

```markdown
# {公司} ESG 月报 · {年份}年{月份}

> 生成日期：{今天}　|　时间窗口：{START} ~ {END}　|　信息条数：{N}

## 一、政策、评级与标准动态
**1. {标题}**
{2-3 句摘要，含关键数字}
来源：{媒体} | 日期：{YYYY-MM-DD} | [链接]({URL})

（3-5 条）

## 二、行业动态与最佳实践
（格式同上，3-5 条）

## 三、公司动态与对标分析
### 3.1 公司本月 ESG 动态
（2-4 条，格式同上）

### 3.2 对标企业关键行动
| 企业 | 关键行动 | 评级/荣誉 | 来源 |
|---|---|---|---|
| ... | ... | ... | [链接](...) |

### 3.3 影响判断与建议
- 基于本月信息，给出 2-3 条针对性建议（每条注明依据哪条信息）
```

## 硬性约束

1. **只用搜到的信息**，不靠模型记忆补全任何事实、数字、日期
2. 每条结论**必须带来源链接和发布日期**
3. 搜索不到足够信息时，如实写"本月公开渠道未检索到相关动态"，**不许编造**
4. 建议部分可以推理，但必须明确标注"基于第X条信息"
5. 全文中文，简洁，每条摘要 2-3 句

## 自检清单（输出前逐条确认）

- [ ] 三块内容都有，且每块至少 2 条
- [ ] 每条都有可点击链接和日期
- [ ] 日期在窗口内（或明确标注为背景补充）
- [ ] 没有模型记忆编造的内容
- [ ] 建议部分有依据标注
