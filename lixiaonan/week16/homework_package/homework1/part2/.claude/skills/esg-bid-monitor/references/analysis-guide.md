# 统计口径与图表规范

**何时读**：report 模式 Phase 3 统计与成报前读本文件。

## 运行统计脚本（权威数字来源）

```bash
python .claude/skills/esg-bid-monitor/scripts/stats.py data/bids.jsonl --start-date 2024-11-24 --end-date 2026-11-24
```

- 输出 JSON 到 stdout（各维度统计）；`--out stats.json` 可同时落盘
- 时间参数按 publish_date 闭区间过滤；不带参数则统计全库
- **报告中出现的每一个统计数字必须与脚本输出一致**——统计靠脚本不靠心算，这是可复现性的底线

## 统计口径

| 统计项 | 口径 |
|---|---|
| 样本 | 仅入库的结构化记录；报告必须声明总样本量 N、来源构成、月度覆盖 |
| 主题计数 | theme 是多标签，各主题计数之和 ≥ N，报告注明"多标签计数" |
| 金额统计 | 仅基于 amount_wan 非空子集；必须同时披露缺失率 |
| 集中趋势 | 均值与中位数并列（大单拉偏均值，中位数更代表典型项目） |
| 月度趋势 | 按 publish_date 所在月聚合条目数与金额合计 |
| 中标格局 | winner 去重计数 + 累计金额双指标 Top10 |

## 金额分桶（单位：万元）

`<50` / `50–100` / `100–500` / `500–1000` / `1000–5000` / `5000–10000`（即5000万–1亿）/ `≥10000`（≥1亿）

分桶统计基于 amount_wan 非空子集；各桶计数之和 = 有金额条目数，与缺失率可对账。

## 图表规范（Mermaid）

- 主题分布 / 采购人类型：`pie`
- 金额分桶 / 省份 Top10：`xychart-beta` 柱状（x 轴用短标签，注明单位"万元"或"条"）
- 月度趋势：`xychart-beta` 折线
- **图表必须紧跟一段文字解读**——只放图不解读是无效输出
- HTML 增强版（可选）：如需交互图表，先调用 dataviz 技能获取配色与设计规范

## 报告中必须如实声明的四件事

1. 样本边界："本报告基于公开可检索样本（N 条），非全量市场数据"
2. 金额可解析率：缺失率多少、缺失条目如何处理
3. 来源构成：一级/二级/三级来源各占多少
4. 检索方式：多关键词扇出的方式与批次，使读者能判断覆盖广度
