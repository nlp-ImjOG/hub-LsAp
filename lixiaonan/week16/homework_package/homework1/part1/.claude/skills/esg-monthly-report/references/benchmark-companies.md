# 对标企业清单（煤炭/能源行业）

本文件为 C 线检索提供"查谁、查什么"的靶点。默认客户为中国神华时直接使用本清单；客户属其他行业时，先检索「<行业> 上市公司 ESG 表现 领先」确定对标名单，再按本文格式建立靶点。

## 使用规则

1. **优先级**：国家能源集团（母公司，天然对标）> A+H 上市同业（披露口径可比）> 地方国企样本。报告期新闻有限时按此优先级检索。
2. **检索角度**：每家至少搜「企业名 + ESG」和「企业名 + 具体靶点」两组；重点是**报告期内**的关键行动（新项目、新披露、新评级、新奖项），而非长期概况。
3. **入报告标准**：第四章对比表中的行动必须有时间、有来源；背景性描述（如"该公司是行业龙头"）不占行动条目。
4. **对比维度**：行动 → ESG 维度（E/S/G）→ 亮点/数据 → 来源。检索时就按这四列记笔记，成报直接取用。
