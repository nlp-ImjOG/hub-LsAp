# 报告模板（Report Structure）

本文件是 esg-monthly-report 的产出模板。**进入 Phase 3（报告生成）前必读**，报告必须严格按下面的结构成文——固定结构让客户跨期阅读时位置稳定，也让质量自查有据可依。

## Report structure

ALWAYS use this exact template:

````markdown
# {客户名称} ESG 月报（{YYYY}年{M}月刊）

> 报告期：{起} ~ {止}　|　客户行业：{行业}　|　编制：ESG 月报 Skill（AI 辅助生成）
> 说明：本报告由 AI 基于公开网络信息编制，供参考，不构成投资或合规建议。

## 摘要

（150~300 字。概括本期政策、行业、公司三个层面最重要的变化，以及最需要注意的一件事。写"发生了什么 + 意味着什么"，不写空泛的"本月 ESG 领域平稳发展"。）

## 本月五大要点速览

| # | 要点 | 层面 | 对客户的意义 |
|---|---|---|---|
| 1 | …（一句话） | 政策/行业/公司/对标 | …（一句话） |

（按重要性排序，不是按章节排序。）

### 1.2 评级动态（评级机构方法调整、客户及同业评级变化）
### 1.3 国际标准进展（ISSB / CSRD / GRI 等，与国内相关的部分优先）

（每节 ≥2 条，条目格式：）

**[N] {事件标题}**（{日期}，{来源机构}）
{2~4 句事实要点，含关键数字与适用范围/时间要求}
**对客户影响：** {1~3 句，落点必须是"这对我意味着什么"：合规义务？披露工作量？评级风险？机遇？}

## 二、行业动态与最佳实践

### 2.1 行业要闻
（≥3 条，格式同第一章，侧重行业整体趋势：保供、价格、绿色转型、安全环保监管等）

### 2.2 最佳实践案例
（2~3 个案例。每个案例写：谁、做了什么、效果/数据、客户可借鉴点。）

## 三、公司动态与 ESG 影响分析及建议

### 3.1 本期公司动态
（客户公司报告期内的新闻/公告/项目动态，≥3 条，格式同上）

### 3.2 ESG 影响分析
（按 E/S/G 三个维度组织：本期相关动态 → 影响分析（正面/负面/中性 + 理由）。有事实依据才写；没有显著动态的维度如实写"本期无显著相关动态"。）

### 3.3 建议行动
（3~5 条。每条格式：**建议**：动作（做什么、怎么做）→ **对应动态**：由哪条信息触发 → **衡量方式**：怎么算做了/做好了。拒绝"加强重视""持续关注"式空话——客户要的是能进工作计划的行动。）

（2~4 段：哪些做法客户已有基础可以加速？哪些是差异化机会？哪些应跟进？）
````

## 写作要求

1. **影响点评分量而行**：政策类落"合规/披露义务变化"，行业类落"竞争格局/成本/机会"，公司类落"评级与利益相关方影响"。一条新闻找不到任何客户影响，就不该出现在报告里。
2. **数字优先**：能带数字的写数字（金额、产能、比例、日期），少用"大幅提升""显著改善"这类模糊表述。
3. **可追溯**：正文每个事实都带 [编号] 来源；两个来源不一致时写明分歧，取更权威一方并注明。
4. **语言**：简体中文，面向客户 ESG 负责人的正式书面语；不使用感叹号，不用营销话术。

## 质量自查清单（写完后逐项核对，全过才交付）

- [ ] 三大必需部分齐全：第一章各节 ≥2 条、第二章要闻 ≥3 条、第三章动态 ≥3 条、第四章 ≥4 家对标企业
- [ ] 每条信息有 [编号] 与日期，附录 A 完整且 URL 可点击
- [ ] 报告期外的数据均标注了实际数据日期
- [ ] 第三章有按 E/S/G 的影响分析 + 3~5 条带衡量方式的建议
- [ ] 摘要、五大要点速览与正文一致；无未标注的推测；无编造内容
- [ ] 全文为正式简体中文，无空话套话
