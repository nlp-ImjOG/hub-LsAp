# 检索手册（Search Playbook）

本文件是 esg-monthly-report 的检索策略库。**进入 Phase 1（信息采集）前必读**；Phase 2（筛选）规则见文末。

目录：
1. 三线检索词库
2. 检索执行技巧
3. 权威来源分级
4. 直访站点清单（WebFetch 兜底）
5. 笔记格式
6. 筛选规则（Phase 2 用）

## 1. 三线检索词库

检索词是"角度"不是清单——从中挑选、组合、变体，不必逐条照搬；同一角度的近义检索词只挑一组即可。`{年}` 替换为报告期所在年份。

### A 线 · ESG 政策 / 评级 / 标准（客户无关，任何客户都要搜）

中文：

- 「上市公司 可持续发展报告 披露 指引/要求」
- 「ESG 披露准则 新规 {年}」
- 「交易所 可持续披露 指南 过渡期」
- 「国资委 中央企业 ESG / 社会责任 报告 要求」
- 「财政部 企业可持续披露 准则」
- 「证监会 ESG 信息披露」
- 「MSCI ESG 评级 方法 调整/更新」
- 「中证 / Wind ESG 评级 规则」
- 「ISSB S1 S2 准则 进展 / 采纳」
- 「CSRD / ESRS 实施 进展」
- 「GRI 标准 更新」

英文（与上面角度对应，扩大覆盖）：

- "ISSB IFRS S1 S2 adoption {year}"
- "CSRD ESRS implementation {year}"
- "MSCI ESG ratings methodology update {year}"
- "China ESG disclosure requirements listed companies {year}"

### B 线 · 行业动态 / 最佳实践（词库随客户行业变化）

煤炭/能源行业（默认示例客户的词库）：

- 「煤炭行业 ESG {年}」
- 「煤炭 绿色矿山 建设」
- 「煤矿 智能化 示范 {年}」
- 「CCUS 煤电 碳捕集 项目」
- 「煤电联营 / 一体化 能源保供」
- 「煤炭 节能降碳 改造」
- 「能源集团 可持续发展报告 发布」
- 「煤炭 上市公司 ESG 评级/报告」
- "China coal industry ESG {year}"
- "coal mine methane / carbon capture China"

其他行业：先检索「<行业> ESG {年}」「<行业> 双碳/可持续发展 最佳实践」建立词库，再按上述结构展开。

### C 线 · 公司与对标（客户名 + 对标企业名；对标清单见 benchmark-companies.md）

- 「<客户名称> ESG」
- 「<客户名称> 可持续发展报告 / 社会责任报告」
- 「<客户名称> 公告 / 中标 / 项目投产 / 签约」（近一月）
- 「<客户名称> 绿色矿山 / 智能化 / 减碳 / 安全」
- 「<客户名称> ESG 评级」（评级数据可放宽时间窗，须标注数据日期）
- 对每家对标企业：「<对标企业> ESG / 减碳 / 智能化 / 可持续发展报告」（近一月）

## 2. 检索执行技巧

- **并行发起**：同一批相互独立的检索放在一次消息里并行调用；A/B/C 三线内部各自并行。
- **先扫日期**：结果先看日期，明显超出报告期的直接跳过，不进笔记。
- **双语并行**：国内政策与公司信息以中文为主；国际标准（ISSB/CSRD/MSCI）中英各搜一组。
- **site: 限定**：需要官方原文时可用站点限定，如 `site:csrc.gov.cn`、`site:sse.com.cn`、`site:cninfo.com.cn`、`site:ifrs.org`。
- **结果去噪**：聚合站/内容农场的转述不进笔记，找到原始出处再记。

## 3. 权威来源分级

| 级别 | 来源类型 | 使用规则 |
|---|---|---|
| 一级（权威） | 监管机构官网（证监会、国资委、财政部、生态环境部、应急管理部等）、交易所（上交所/深交所/港交所）、公司公告（巨潮资讯、公司官网）、国际标准组织（ISSB/IFRS、EFRAG、GRI） | 直接采用，可作报告主论据 |
| 二级（可信） | 主流财经/综合媒体（新华社、人民日报、证券时报、上海证券报、中国证券报、21世纪经济报道、财新、第一财经等）、行业媒体（中国煤炭报、中国能源报等） | 采用；关键数字尽量回溯一级源交叉验证 |
| 三级（低置信） | 自媒体、论坛、无署名转载、内容农场 | 默认弃用；确有价值时标注「来源可信度低」，不作为主论据 |

## 5. 笔记格式

每条发现按此格式追加到 `reports/notes-<客户名称>-<YYYY-MM>.md`：

```
### [线别-A/B/C] <一句话标题>
- 日期：<YYYY-MM-DD>（不确定时写"日期不详"）
- 来源：<机构/媒体名>（分级：一/二/三）：<URL>
- 要点：<2~4 句事实摘要，含关键数字>
- 初判：<与客户的关系一句话；明显无关直接标记"弃">
```

笔记文件头固定写入：客户、行业、报告期、检索完成时间。

## 6. 筛选规则（Phase 2 用）

按顺序执行，任何一条不过即落选：

1. **时间窗**：事件日期落在报告期内。例外两类可放宽——① 评级/评级方法类数据；② 长周期项目类动态——放宽时必须在笔记和报告中标注实际数据日期。
2. **来源分级**：一级、二级进入候选；三级默认落选（除非独此一家且价值高，标注后使用）。
3. **去重**：同一事件只保留来源级别最高、细节最全的一条，其余在笔记中注明"并入#"。
4. **相关性**：与客户或其行业的 ESG 关联是否直接？牵强的热点不硬凑——月报宁缺毋滥。
5. **数量下限**：筛选后三线各 ≥5 条。不足的线回到 Phase 1 换角度补检；确实无米下炊时，在报告中如实说明"本期该层面信息有限"，不要灌水。
