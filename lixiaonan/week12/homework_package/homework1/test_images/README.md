# 测试样本说明

按 `期望等级_序号.图片后缀` 命名放入本目录，每类建议 2~3 张，M1 验收脚本
`tools/test_m1.py` 会自动扫描并核对：

| 前缀 | 期望等级 | 拍什么 |
|---|---|---|
| `high_` | high 高风险 | 楼道内电动车、电瓶、飞线充电 |
| `medium_` / `mid_` | medium 中风险 | 大量纸箱、木质家具堵路 |
| `low_` | low 低风险 | 少量堆物（一两件鞋子、纸袋） |
| `none_` / `clean_` | none 无风险 | 干净整洁的楼道 |
| `not_corridor_` | not_corridor 非楼道 | 室外、客厅、人物等无关图片 |

例：`high_1.jpg`、`medium_1.jpg`、`low_1.jpg`、`none_1.jpg`、`not_corridor_1.jpg`

样本来源建议：
- 案例 notebook 的 `./data/` 目录中已有标注图片
- 或自行拍摄/收集后按上表重命名

补充建议：加入夜景、模糊、俯拍/仰拍等边界样本（`high_2_night.jpg` 等同样按首个
下划线前缀识别），观察模型在低质量输入下的稳定性。
