# ESG 投标信息汇总 Skill

两类任务，一个 Skill 覆盖：

- **历史汇总**：过去 2 年 ESG / 可持续发展 / 双碳 相关中标信息 → 热点方向 + 金额分布分析；
- **每日监控**：每天抓取新增招标 / 中标信息 → 去重 → 推送。

## 工作流

### 历史汇总

1. **检索**：按下方关键词，覆盖 ESG 报告编制、评级咨询、碳核查/碳盘查、碳足迹/CBAM、双碳方案、碳资产/CCER、ESG 数据平台、绿色认证等方向。
2. **抽取**：从每条结果抽取「项目标题、采购方、中标金额、日期、类别」。
3. **归一化**：金额统一换算为「万元」（支持 元/万/万元/亿元）。
4. **聚合分析**：按类别、采购方、半年时段、金额区间统计项目数与金额。
5. **成稿**：输出概览、热点方向表、金额分布表、明细表。

### 每日监控

1. 检索当日新增 ESG 招标 / 中标信息；
2. 与本地去重库（`seen_bids.json`）比对，只保留新增；
3. 通过企业微信 / 钉钉 webhook 推送，并落盘 `每日招标推送_{日期}.md`。

## 检索关键词模板

`ESG 中标公告`、`可持续发展报告 编制 咨询 中标`、`双碳 碳达峰 碳中和 方案 中标`、`碳核查 碳盘查 中标`、
`碳足迹 CBAM 咨询 中标`、`ESG评级 提升 咨询 中标`、`碳管理 平台 建设 中标`、`绿色工厂 绿色供应链 认证 中标`、
`CCER 碳资产 开发 中标`、`ESG 数据平台 中标`。

## 确定性脚本（推荐优先）

```bash
# 历史汇总（近 2 年）
python scripts/esg_bid_monitor.py --mode history --years 2 --out 作业1/案例2-ESG投标/output

# 每日监控 + 推送（可配 cron / 定时任务每日运行）
python scripts/esg_bid_monitor.py --mode daily --push --out 作业1/案例2-ESG投标/output

# 离线演示
python scripts/esg_bid_monitor.py --demo --mode history --out 作业1/案例2-ESG投标/output
```

金额解析、去重、聚合统计是确定性逻辑（正则 + 字典聚合），脚本化可保证**口径一致、可复现**；
仅有「从杂乱网页抽取结构化中标字段」这一步交给 LLM，兼顾确定性与灵活性。

## 输出

- 历史汇总：`output/ESG中标信息汇总_{日期}.md`
- 每日推送：`output/每日招标推送_{日期}.md` + `output/seen_bids.json`（去重库）
