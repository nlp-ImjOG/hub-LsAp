# ESG 月报生成 Skill

为客户的 ESG 管理工作产出可交付的**月度报告**：自主联网搜索 → 自主筛选 → 结构化总结 → 成稿。

## 输入

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| 客户公司 | 中国神华 | 上市公司全称/简称 |
| 所属行业 | 煤炭 / 煤电一体化 | 用于行业新闻检索 |
| 对标企业 | 兖矿能源、陕西煤业、中煤能源、国家能源集团 | 逗号分隔 |
| 统计区间 | 近 30 天 | 报告覆盖时间窗 |

## 工作流（按顺序执行）

1. **确定画像**：确认客户公司、行业、对标企业；若用户未指定，使用默认值（中国神华）。
2. **联网检索**：按下方「检索关键词模板」，对四类内容分别搜索，每类至少 3 组关键词。
3. **筛选与核实**：
   - 保留近一个统计区间内的信息；剔除重复、广告、来源不明的条目；
   - 优先采信交易所/政府官网、行业协会、公司官网、权威评级机构（MSCI/华证/万得/CDP）等来源；
   - 对无法确认日期的条目标注「日期待核」。
4. **结构化摘要**：对每条信息概括事实（一两句），并标注其「ESG 关联」与「对客户建议」。
5. **成稿**：按下方「报告结构」生成 Markdown，落到 `output/` 目录。

## 检索关键词模板

- **政策 / 标准 / 评价**：`ESG 政策 最新`、`可持续发展报告 披露 指引 交易所`、`碳市场 双碳 政策`、`ESG 评级 标准 ISSB`
- **行业**：`{行业} ESG 双碳 新闻`、`{行业} 最佳实践 绿色转型 智能矿山`
- **客户公司**：`{客户} ESG 可持续发展`、`{客户} 双碳 CCUS 绿色矿山`、`{客户} ESG 评级 MSCI 华证 万得`
- **对标企业**：`{对标} ESG 双碳 行动`（每个对标一条）

## 报告结构（必须覆盖）

1. 执行摘要（本期要点 + 总条数 + 3~5 条建议）
2. 一、ESG 政策 / 标准 / 评价动态
3. 二、行业新闻与最佳实践
4. 三、客户公司动态：ESG 影响与建议
5. 四、对标企业 ESG 关键行动
6. 五、风险提示与下一步行动建议

每条信息尽量给出：动态/政策名、来源、日期、要点、ESG 关联、对客户建议。

## 确定性脚本（推荐优先）

本 Skill 的高代码实现已沉淀为脚本，直接运行可一步成稿，且结果可复现：

```bash
# 离线演示（无网络/无 Key）
python scripts/esg_monthly_report.py --demo --out 作业1/案例1-ESG月报/output

# 真实联网
python scripts/esg_monthly_report.py --company 中国神华 --days 30 --out 作业1/案例1-ESG月报/output
```

- 无脚本时：由模型自行规划检索词、逐条调搜索、临场组织文字，结果每次不同、易漏项；
- 有脚本时：搜索→抓取→去重→结构化摘要→成稿为固定流水线，仅「摘要与判断」交给 LLM，确定性高、可复现、可审计。
详见 `../作业2/对比报告.md`。

## 输出

- 文件：`output/{客户}ESG月报_{YYYY-MM}.md`
- 首行标注统计区间与生成时间；演示稿需标注「⚠ 演示稿」。
