## 取证命令与复算结果

在作业根目录以 PowerShell 运行。两个命令均完成联网提取并生成 JSON。销售文件保留归档查询、附件地址、下载时点、文件 SHA-256 和两张表，财务文件保留同次申报、逐项标签、期间类型与原始美元数。原始数据与计算结果分别位于 JSON 的 `evidence` 和 `summary`。

```powershell
python .agents/skills/sales-evidence-report/scripts/sales.py --year 2025 --out 证据/sales.json
python .agents/skills/financial-evidence-report/scripts/financial.py --cik 320193 --year 2025 --out 证据/financial.json
```

分别对两份 JSON 通过脚本的 `--replay` 离线复算，两个 `summary` 均逐字段相同。此项检验计算可复现性。另用年报、业绩附件及半年报原文按下表检查输入、方向和口径。
