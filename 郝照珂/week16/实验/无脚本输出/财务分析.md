# Apple FY2025 财务分析

**每 100 美元净利润对应 99.5 美元经营现金流，但新增利润没有带来新增现金。** 净利润增加 18,274（+19.5%），经营现金流减少 6,772（−5.7%）。经营现金流扣除固定资产购建支出后仍有 98,767，当年回购与股息现金支出合计 106,132，超过这笔自由现金流 7,365。决定回购节奏时，应先确认税款支付后的经常性现金转化及债务到期安排。[Apple FY2025 10-K，第 29、31、33 页](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

口径为 Apple Inc. 合并美国 GAAP，金额均为百万美元。FY2024 截至 2024 年 9 月 28 日，FY2025 截至 2025 年 9 月 27 日，两期均为 52 周。利润及现金流为全年发生额，资产负债为期末余额。资料截止 FY2025 年报提交日 2025 年 10 月 31 日。[SEC 提交记录](https://www.sec.gov/Archives/edgar/data/320193/0000320193-25-000079-index.html) · [年报附注 1](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

## 利润增长中，约一半来自所得税费用减少

| 全年利润表 | FY2024 | FY2025 |
|---|---:|---:|
| 净销售额 | 391,035 | 416,161 |
| 销售成本 | 210,352 | 220,960 |
| 毛利 | 180,683 | 195,201 |
| 营业费用 | 57,467 | 62,151 |
| 营业利润 | 123,216 | 133,050 |
| 其他收入／费用净额 | 269 | −321 |
| 税前利润 | 123,485 | 132,729 |
| 所得税费用 | 29,749 | 20,719 |
| 净利润 | 93,736 | 112,010 |
| 毛利率（毛利／收入） | 46.2% | 46.9% |
| 营业利润率（营业利润／收入） | 31.5% | 32.0% |
| 实际所得税率（所得税费用／税前利润） | 24.1% | 15.6% |

收入增长转化为毛利增加 14,518，扣除新增营业费用 4,684 后，营业利润增加 9,834。税前利润增加 9,244，所得税费用减少 9,030，两者恰好解释净利润的 18,274 增量。管理层指出，欧盟国家援助裁决相关项目的年度税费影响从上年费用 10,246 变为本年利益 486，推动实际税率下降，其他税务因素部分抵消了影响。营业利润率上升约 0.5 个百分点，比净利润增幅更适合衡量当年经营效率的变化。[年报，第 25 页「Provision for Income Taxes」、第 29 页利润表及附注 7 税率调节表](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

现金流量表的调节项目合计比上年减少 25,046，超过净利润增量。最大差异是其他流动与非流动负债对现金流的贡献从正转负。应付款增加所带来的现金贡献也减少 5,118，应收账款多占用现金 2,894。存货占用改善和非现金费用加回抵消了一部分。表中数字来自现金流量表的调节行，避免用两期资产负债表的余额之差替代现金影响。[年报，第 33 页「Operating activities」](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

税款的跨期结算提供了具体线索。FY2024 苹果已经确认上述一次性税费，年末有约 15,800 的受限资产用于清偿爱尔兰税款。FY2025 上半年，苹果从托管账户释放折合约 15,400 并结清该项义务。全年现金支付所得税较上年增加 17,267，与利润表税费减少的方向相反。现金税款是现金流量表的补充披露，重复扣减会高估影响。负债调节行包含多种项目，现有明细无法把整笔 26,628 的同比变化归因于税务结算。[年报，附注 4、7 及第 33 页](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm) · [FY2025 第二季度 10-Q，第 17 页「State Aid Decision Tax Payable」](https://www.sec.gov/Archives/edgar/data/320193/000032019325000057/aapl-20250329.htm)

## 流动性与资本分配

| 期末资产负债表 | FY2024 | FY2025 |
|---|---:|---:|
| 现金及现金等价物 | 29,943 | 35,934 |
| 流动有价证券 | 35,228 | 18,763 |
| 流动资产 | 152,987 | 147,957 |
| 非流动有价证券 | 91,479 | 77,723 |
| 非流动资产 | 211,993 | 211,284 |
| **总资产** | **364,980** | **359,241** |
| 流动负债 | 176,392 | 165,631 |
| 非流动负债 | 131,638 | 119,877 |
| **总负债** | **308,030** | **285,508** |
| **股东权益** | **56,950** | **73,733** |
| 净营运资本（流动资产减流动负债） | −23,405 | −17,674 |
| 流动比率（流动资产／流动负债） | 0.87 倍 | 0.89 倍 |

两年资产负债恒等式的差额均为零。FY2024 为 308,030 + 56,950 = 364,980，FY2025 为 285,508 + 73,733 = 359,241。期末营运资本缺口收窄 5,731，原因是流动负债比流动资产降得更快。现金和流动、非流动有价证券合计从 156,650 降至 132,420，其中 FY2024 年末余额包含前述受限资产。管理层判断，期末储备、持续经营流入及债务市场融资可满足未来十二个月及以后的资金需求。评估短期偿付时应另看证券到期日与可动用性。[年报，第 25 页「Liquidity and Capital Resources」、第 31 页资产负债表、附注 4](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

资本支出增加 3,268，叠加经营现金流减少 6,772，自由现金流共减少 10,040。回购加股息由 110,183 降至 106,132，两年均超过当年自由现金流，差额从 1,376 扩至 7,365。当年有价证券到期与出售所得超过购入额 29,390，投资活动因此提供净现金，使得期末现金仍上升。回购以**现金流量表实际支付额**计量。董事会批准的计划仅规定回购上限，资金排程可以调整。[年报，第 26 页「Capital Return Program」及第 33 页投资和筹资现金流](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)

建议财资团队在下次回购决策前提供三项数据。第一，拆分其他经营负债的税款、应计费用和结算日期，核实哪些现金压力已经消退。第二，把客户应收账龄及期后回款与 FY2025 年末余额核对，判断收款压力是否延续。第三，用可动用现金、证券到期和经营现金预测覆盖短债、税款、资本支出和已宣告股息，再测算可执行的回购额。
