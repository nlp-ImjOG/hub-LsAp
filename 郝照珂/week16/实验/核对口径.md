# 对照实验的核对口径

在查看任一组报告前固定下列检查项。两组共用[同一题面](题面.md)。分别开一个无历史上下文的执行会话，各写两份报告；报告起草时不能查看另一组的输出。无脚本组可使用网页搜索与原文阅读；有脚本组额外使用技能附带的 Python 程序。检索、计算和归纳均由各组自行完成。

| 检查项 | 核对方法 |
| --- | --- |
| 销售报告的 60 个数字 | 五个产品类别、五个地区，每行检查上期金额、本期金额、变化额、同比、本期占比、对公司净增量的贡献。与公司年度栏和重新计算的结果逐格比较，按报告显示的小数位四舍五入。 |
| 财务报告的 30 个数字 | 两年各核对收入、毛利、营业利润、净利润、总资产、总负债、权益、流动资产、流动负债、经营现金流、资本支出、自由现金流、现金转化率、流动比率、营业利润率，接受等价单位与百分比。 |
| 定性证据 | 各核查四点。销售看服务的增长来源、大中华区拖累项、两套分类口径、销量/价格数据缺口。财务看上年税务事项、经营现金流调节项、回购与分红的资金覆盖、流动性比率的局限。分别标为“有证据支持”“缺失”或“证据不足”，不合成主观总分。 |
| 证据与复算 | 打开原文，确认年度列、报表表名或页码；统计可直接复用的机器可读证据文件。对固定输入再运行脚本，比较输出字节；临时改变一项销售金额或资产金额，检查程序是否拦截勾稽差异。 |

销售底数对照 [Apple 业绩附件第 1 页年度列](https://www.apple.com/newsroom/pdfs/fy2025-q4/FY25_Q4_Consolidated_Financial_Statements.pdf)；财务底数对照同一附件第 1–3 页和 [FY2025 10-K 第 29–33 页](https://www.sec.gov/Archives/edgar/data/320193/000032019325000079/aapl-20250927.htm)。金额按百万美元核对。出现漏项单列，方向正确但数值超出显示精度仍记为差异。每组各运行一次；不据此估计平均耗时、成本或普适准确率。
