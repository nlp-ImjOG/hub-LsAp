# 销售数据分析

先确定企业、财年与对比期。搜索“公司 + 财年 + annual report / 年度报告 + net sales / 分部收入”，再搜索公司投资者关系站的同期业绩附件。打开原文，核对企业、期间、币种、单位、是否重列。把搜索结果中的季度快讯、重复转载或错期文件记入简短的筛选记录。引用到表名、页码或章节及可访问的原文链接。公司重发同一数据可核对抄录，不能视为独立验证。

以合并净销售额为锚点，使用披露的完整分类。分产品与分地区是同一笔收入的两个视角，各自对总额勾稽。记录两期原值、增量、同比、本期占比与增长贡献。同比用上期该项作分母，贡献用公司净增量作分母，允许负值和超过 100%；分母为零时注明不适用。分部含内部交易时先处理抵销。单位换算和四舍五入留在展示层，无法核对的差额要显示。

向经营负责人解释谁贡献最多、谁拖累、销售规模与增长贡献如何不同。对原因区分管理层披露、计算结果和分析假设，不从金额推断销量。结合证据提出能在下一次经营复盘中验证的问题，写明还缺什么数据。正文包含摘要、数字表、证据出处和筛选说明。用用户指定语言，默认中文。
