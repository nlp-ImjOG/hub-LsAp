# 财务报表分析

明确报告主体、财年、币种和单位。搜索监管披露库中的该年合并年报，再检索公司投资者关系网站的同期财务报表。打开表格核实期间和会计口径，优先采用审计年报，记录补充来源、排除的错期或二手材料及其原因。引用到章节或表名和原文链接。同一发行人两处披露可用来核对数字，但信息来源相关。

提取两期利润表、期末资产负债表和完整财年现金流量。展示底数，使读者能复核毛利率、营业利润率、流动比率、经营现金流/净利润、自由现金流（经营现金流减购建固定资产的现金支出，列示支出正数）。资产等于负债加权益；自由现金流是分析用的衍生指标。区分财年流量和期末余额、百分比和百分点、GAAP 与调整口径；上年为零时不计算增长率。

围绕利润和现金是否同向、短期流动性和资本配置组织报告。发生背离时沿现金流量表的调节项目找主要金额，再检查税务、回购或其他相关附注。结论应指出哪部分可以定量解释，哪部分仍需更多证据。给出可追踪指标和证据局限。正文包含摘要、两期对照表、计算说明和来源筛选记录。用用户指定语言，默认中文。
