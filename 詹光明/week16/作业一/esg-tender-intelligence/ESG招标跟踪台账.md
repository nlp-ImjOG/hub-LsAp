## 二、状态说明

| 状态 | 含义 | 处理规则 |
|---|---|---|
| 新发现 | 首次进入台账，尚未评估 | 24 小时内完成资格与匹配度初筛 |
| 评估中 | 正在做资格、案例、报价评估 | 补充负责人/伙伴/报价策略（不写入本表敏感信息） |
| 已投标 | 已提交投标文件 | 跟踪开标/候选人/结果 |
| 已截止 | 报名或投标已截止 | 等待结果；无结果则关闭 |
| 已中标 | 已有中标/成交结果 | 记录中标方与金额，用于竞争分析 |
| 放弃 | 评估后不投 | 记录原因（资质/地域/客户关系/价格） |
| 流标 | 招标失败/重新招标 | 关注二次公告 |

## 四、去重规则

1. 先按"项目名称 + 采购人"匹配；名称不一致时按"项目编号"匹配。
2. 同一项目多平台转载只保留一条，来源取官方原文，聚合源写入备注。
3. 多标段项目原则上合并为一条，金额写合计；如需分别跟踪，在备注中列标段。
4. 状态只向前推进，不回退；重新招标时新建一条并关联原项目编号。
