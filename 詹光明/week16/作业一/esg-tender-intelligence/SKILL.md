# ESG 投标信息汇总

## 概述

**核心原则：先定口径，再去重；只写有来源的项目；金额必须区分预算/中标/候选人；样本不等于全市场。**

本技能有两种模式，均不依赖脚本，只使用内置 WebSearch / WebFetch 检索公开信息，并用 Markdown 写作：

- **复盘模式**：汇总近 24 个月 ESG、可持续发展、双碳相关的中标/成交样本，分析热点、金额分布、采购人与竞争格局。
- **日报模式**：每日增量监控，去重、分级、截止提醒、更新 Markdown 台账。

## 何时使用

**使用：**
- ESG 咨询/服务机构找商机、判断预算与中标价、分析竞争对手
- 企业 ESG/采购部门了解市场供给、服务商报价区间与同类做法
- 每天/每周监控新招标，形成可执行的投标清单

**不适用：**
- 需要全量数据库（付费标讯）才能保证完整性的统计
- 自动投标、自动报价、自动发邮件/企微/钉钉（本技能只生成内容）
- 法律意见、资质审查、围标串标识别

## 第 1 步：定义口径（最容易出错）

| 口径 | 规则 |
|---|---|
| 金额 | 预算金额、最高限价、中标金额、成交金额、候选人报价、合同金额必须分列；**金额分析以中标/成交为主，候选人报价可纳入但必须标注，预算/上限不得混入** |
| 状态 | 招标公告、变更公告、候选人公示、中标结果、合同公告、终止/流标要区分；**候选人不能写成中标人** |
| 项目 | 同一项目多平台发布，按“项目名称 + 采购人 + 项目编号”去重，保留最新状态 |
| 时间 | 以公告发布日期为准；中标结果日与合同日分开记录 |
| 服务 | 只纳入咨询/报告/核算/规划/平台/评价/培训等服务；纯设备、EPC、工程总包不纳入，除非含明确 ESG/碳咨询内容 |
| 样本 | 公开网页检索不能保证全量；报告必须写“样本 N、来源、覆盖平台、未覆盖平台、金额披露率” |

## 第 4 步：检索执行

### 复盘模式

1. 按关键词矩阵拆成 20–30 条查询，覆盖窗口内各年度（如 2024–2026）。
2. 优先找**中标/成交公告**，其次候选人公示；预算公告只用于判断未来商机。
3. 目标收集 40–60 条**披露金额**的记录；不足时如实说明样本量。
4. 对高价值项目用 WebFetch 打开原文，核对采购人、中标方、金额、日期、服务期。
5. 把每条记录写入原始表，再进入第 5 步结构化。

### 日报模式

1. 窗口：上次运行日至今天；首次运行回看 7 天（可扩到 14 天）。
2. 用日期限定词检索，按发布日期排序。
3. 先读台账，按“项目名称 + 采购人”去重。
4. 对截止 ≤7 天的项目标 P0，对预算/中标 ≥100 万或战略客户标 P1。
5. 输出日报，并把新增/更新写回台账。

## 第 5 步：结构化字段

| 字段 | 说明 |
|---|---|
| 项目名称 / 项目编号 | 以公告原文为准 |
| 采购人 / 采购人类型 | 央企、地方国企、政府/园区、上市公司、金融机构、高校/事业单位 |
| 行业 / 地区 | 采购人所属行业、项目所在地 |
| 公告类型 | 招标、变更、候选人、中标、成交、合同、终止/流标 |
| 发布日期 / 截止日期 / 开标日期 | 分别记录，不要混用 |
| 预算金额 / 最高限价 | 万元；无则“未披露” |
| 中标金额 / 金额类型 | 中标、成交、候选人报价、合同；**不要用预算代替** |
| 中标供应商 | 联合体写牵头方 + 成员；未知写“未披露/待定” |
| 服务内容 / 服务期 | 报告、咨询、核算、规划、平台、评价、培训等 |
| 招标方式 | 公开招标、竞争性磋商、询比、谈判、单一来源 |
| 来源链接 / 可信度 | 官方高、聚合中；标注“待核实” |
| 状态 / 首次发现 / 最后更新 | 新发现、评估中、已投标、已截止、已中标、放弃、流标 |

**规则：**
- 金额单位统一万元，保留 2 位小数；外币注明币种与汇率口径。
- 金额未知写“未披露”，不要估算。
- 多标段分别记录，不合并金额，除非公告给出总金额。
- 同一项目多次公告合并，保留最新状态，不删除历史。

| 编号 | 类别 | 典型内容 |
|---|---|---|
| 1 | ESG 报告/信息披露 | ESG/CSR/可持续发展报告编制、设计、印刷、鉴证 |
| 2 | ESG 咨询/管理提升/评级 | ESG 战略、管理体系、评级提升、双重重要性、培训 |
| 3 | 碳盘查/碳核算/碳足迹/碳标签 | 组织碳盘查、产品碳足迹、碳标签、因子库、核查 |
| 4 | 碳资产/碳交易/CCER | 碳资产开发、CCER 方法学、碳交易策略 |
| 5 | 双碳规划/零碳园区/碳排放预算/双控 | 碳达峰路径、零碳园区、碳排放预算、能耗双控转碳双控 |
| 6 | 碳管理/ESG 数字化平台 | 能碳平台、碳资产管理平台、ESG 数据系统 |
| 7 | ESG 评价/工程 ESG | 项目 ESG 评价、绿色园区评价、工程 ESG 技术服务 |
| 8 | 绿色金融/转型金融/绿色债券 | 绿色信贷、转型金融、绿色债券评估 |

| 10 | 其他 | 会务、传播、研究课题等 |

**优先级：**
- **P0**：截止 ≤7 天，且与目标行业/服务匹配
- **P1**：预算/中标 ≥100 万，或战略客户（央企总部、省级政府、头部上市公司）
- **P2**：其他匹配项目
- **P3**：不匹配/纯设备/纯工程

**打分：** 匹配度 × 金额 × 时效 × 客户价值（各 1–3 分），≥6 分入选。

## 第 7 步：历史复盘分析（必须包含）

1. **样本说明**：N、时间窗口、来源、金额披露率、覆盖平台、局限。
2. **总量与趋势**：年度/季度项目数、已披露金额、中位数、均值；月份可核实则按季度，否则按年度；上一年与本年 YTD 对比。
3. **金额分布**：分档统计项目数与金额占比；中位数/均值；按类别拆分。
4. **类别结构**：数量占比 vs 金额占比，识别“高频低价”与“低频高价”。
5. **热点主题**：Top 3–5，给出项目数、金额、代表项目、政策驱动。
6. **采购人与区域**：央企/地方国企/政府园区/上市公司/金融；Top 省份；注明样本偏差。
7. **竞争格局**：中标频次、重复中标、专业化、联合体。
8. **价格基准**：按类别给出中位数与区间，区分报告/咨询/核算/规划/平台。
9. **投标启示**：赛道选择、报价、资质、联合体、客户优先级。
10. **局限**：公开数据不完整、金额未披露、重复公告、区域偏差。

**金额分档建议：** <10、10–30、30–50、50–100、100–300、300–500、500–1000、>1000 万元。

**规则：**
- 每次日报先读台账，按“项目名称 + 采购人”去重。

## 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 预算当中标价 | 高估市场 | 分列金额类型，分析以中标/成交为主，候选人标注 |
| 候选人当中标人 | 误判竞争 | 标注状态，等最终结果 |
| 同一项目多平台重复 | 样本虚高 | 项目名称 + 采购人 + 编号去重 |
| 只搜“ESG” | 漏掉双碳/可持续 | 用关键词矩阵 |
| 用全国数据冒充全量 | 误导决策 | 写样本 N 与覆盖平台 |
| 推送旧闻 | 错过截止 | 以发布日期为准，日报只看窗口 |
| 忽略截止日 | 无法投标 | 日报置顶截止提醒 |
| 服务/设备混在一起 | 金额失真 | 服务口径过滤 |
| 台账不更新 | 重复推送 | 每次先读台账 |

## 与定时任务配合

- **手动**：每天说“跑今天的 ESG 招标日报”。
- **自动**：用 `/loop` 或操作系统计划任务每天触发一次；本技能不创建定时任务、不发送邮件。
- **示例**：`/loop 1d 用 esg-tender-intelligence skill 跑今天的 ESG 招标日报，更新台账`（具体命令以你的 Claude Code 版本为准）。
- **推送渠道**：对话内输出 + Markdown 台账；如需邮件/企微/钉钉，另行配置，不写入本技能。
