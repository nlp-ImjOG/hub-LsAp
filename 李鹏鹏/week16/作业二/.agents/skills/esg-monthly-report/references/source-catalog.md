# 信源目录与检索式

> 六方向分层清单。**每个方向至少 2 组关键词、跨 2 个信源层级**，否则必然漏掉关键节点。

## 信源分级

| 层级 | 用途 | 说明 |
| --- | --- | --- |
| **T1 一级（法规/监管原文）** | 结论的唯一依据 | 部委、交易所、国际准则机构官网 |
| **T2 二级（机构解读）** | 补充背景与数据 | 行业协会、评级机构、交易所研究、专业律所/咨询 |
| **T3 三级（财经媒体）** | 发现线索、补充时间线与数字 | 第一财经、财新、中国证券报、新浪财经 |
| **T4 四级（自媒体/聚合）** | 仅作线索，**不作引用** | 公众号、文库站、论坛 |

## 方向一：国内政策与标准（T1 为主）

| 机构 | 关注内容 | 检索式 |
| --- | --- | --- |
| 财政部（会计司/会计准则委员会） | 可持续披露基本准则、气候准则、鉴证准则、行业应用指南、意见征集 | `财政部 可持续披露准则 征求意见`、`气候准则 行业应用指南`、`财会便函` |
| 生态环境部 | 企业环境信息依法披露、碳市场配额方案、CCER、碳足迹、甲烷 | `生态环境部 配额总量 分配方案`、`企业环境信息依法披露`、`甲烷 控排` |
| 发改委 / 能源局 | 双碳政策、煤电低碳化改造、节能降碳、新型能源体系 | `煤电低碳化改造建设行动方案`、`双碳 行动方案 发布` |
| 证监会 / 交易所 | 可持续发展报告指引、信息披露评价 | `上交所 可持续发展报告指引`、`信息披露工作评价` |
| 市场监管总局 / 标准委 | 碳排放标准、碳足迹标识、ISO 提案 | `碳排放 国家标准 发布`、`碳足迹 标识认证` |
| 全国人大 | 生态环境法典、能源法 | `生态环境法典 通过 施行` |

## 方向二：国际规则与标准（T1/T2）

| 机构 | 关注内容 | 检索式 |
| --- | --- | --- |
| ISSB / IFRS 基金会 | IFRS S1/S2、自然相关披露、实务公告 | `ISSB 征求意见稿`、`IFRS S2 自然` |

| ISO | TC207 环境管理、甲烷监测等新标准 | `ISO 立项 碳排放` |

## 方向三：评级与指数（T2）

| 机构 | 关注内容 | 检索式 |
| --- | --- | --- |
| MSCI | ESG 评级模型版本、评级结果变动 | `MSCI ESG 评级 5.0`、`MSCI 评级 上调` |
| S&P Global | CSA 评分、行业排名 | `标普 CSA 评分` |
| CDP | 气候/水/森林问卷结果 | `CDP 评级 A 名单` |
| 中证指数 | 中证 ESG 评价方法版本、评价结果 | `中证ESG评价方法 V` |
| 华证 / Wind / 商道融绿 | 评级结果、榜单、白皮书 | `华证 绿色低碳先锋榜` |
| 香港会计师公会等 | 港股 ESG 奖项与评审导向 | `最佳企业管治及ESG奖` |

> 评级类要特别注意**"方法论更新"比"评级结果"更重要**：方法论变更意味着下一期结果可能异动，属于前瞻信息。

## 方向四：行业层面

| 来源 | 关注内容 |
| --- | --- |
| 行业协会（如中国煤炭工业协会、中钢协） | 行业数据、行业自律、对国际规则的官方态度 |
| 行业"十五五"规划 / 五年规划 | 行业总量与结构目标（决定长期排放路径） |
| 国家级试点（标准化试点、碳达峰试点） | 政策落地样板，往往预示未来强制要求 |
| IEA / 世界能源展望 / 清华全球碳中和进展报告 | 国际比较与在运项目统计 |
| 头部企业年报/ESG 报告 | 行业最佳实践的真实数据 |

## 方向五：客户公司（T1 公告 + T3 报道）

| 渠道 | 取什么 |
| --- | --- |
| 上交所/深交所/港交所公告 | 定期报告、临时公告、ESG 报告全文 |
| 公司官网新闻/投资者关系 | 项目进展、获奖、活动（注意：宣传口径） |
| 投资者关系活动记录表 | **产量变动原因、资本开支计划、目标承诺**（信息密度最高） |
| 互动平台问答（如"互动易""上证 e 互动"） | 投资者关注点（**不得当作事实引用**） |
| 月度/季度运营数据公告 | 产量、销量、运量（做强度指标分母） |

## 方向六：对标企业

只取**可对比**的信息：同一议题、同一指标口径。对标表建议固定维度：排放总量、排放强度、范围三进展、气候财务量化、技术路径、管理机制、外部评级。

## 检索式模板

```text
# 政策：抓时间节点
{机构} {主题} 发布 | 施行 | 征求意见 | 截止 | 解读

# 评级：抓变化
{公司} {机构} ESG 评级 上调 | 下调 | 维持 | 方法论 | 模型版本

# 公司：抓事实
{股票代码} 公告 | 运营数据 | ESG | 投资者关系

# 行业：抓首创与标准
{行业} 首个 | 试点 | 标准 | 立项 | 规划

# 国际：抓对华影响
{规则} 中国 影响 | 默认值 | 清缴 | 扩围
```

## 时效陷阱

统计期为"过去一个月"时，检索必须同时覆盖：

1. 统计期内**发布**的内容；
2. 统计期前 60 天内**发布、但统计期内生效或截止**的内容（最容易漏）；
3. 统计期前发布、但统计期内**出现重大进展**（如征求意见稿转为正式稿）的内容。

写成报告时，第 2、3 类标注"（背景）"并给出原始发布时间。
