# ESG 月报生成技能

把"过去一个月的 ESG 信息噪声"压缩成"客户能直接上会的一份月报"。
核心不是罗列新闻，而是**替客户完成三件事**：判断哪些变化与他有关、影响有多大、下一步该做什么。

## 何时使用

- 需要按月为客户/本公司生成 ESG 简报、政策监测报告、行业动态月报
- 需要把零散的 ESG 新闻整理成有影响判断和行动建议的文件
- 需要做特定企业的 ESG 对标梳理（客户公司 vs 同业）

不适用：一次性深度专题研究（如"某行业 ESG 披露质量评估"）、需要原报告的翻译。

## 硬性质量线

一份合格的月报必须满足以下五条，缺一条即不合格：

1. **时效**：所有条目落在统计期内；期外的重要背景需显式标注"（背景）"并注明原发布时间。
2. **可核验**：每条事实带来源机构 + 发布日期 + 链接，附录统一编号；无来源的判断写成"分析"而非"事实"。
3. **有关联**：每条信息都要回答"与客户有什么关系"，不得出现纯新闻搬运。
4. **有量化**：能落数字就落数字（金额、比例、吨数、亿千瓦时、评级档位），避免"大幅""显著"等空词。
5. **可执行**：建议动作要写到"做什么、谁来做、什么时候前完成"，不写"加强重视"这类废话。

## 流程

### 第 0 步：锁定参数（不确认就开工会返工）

向用户确认或自行推定并在报告首页写明：

| 参数 | 说明 | 示例 |
|---|---|---|
| 客户主体 | 全称、股票代码、上市地 | 中国神华能源股份有限公司（601088.SH / 01088.HK） |
| 统计期 | 默认上月 25 日至本月 24 日 | 2026-10-25 ~ 2026-11-24 |
| 所属行业 | 决定行业信源与对标组 | 煤炭开采与洗选、煤电、煤化工 |
| 对标组 | 3–5 家，同行业 + 同披露口径 | 中煤能源、陕西煤业、兖矿能源、中国神华 |
| 关注重点 | 用户特别关心的议题（可选） | 甲烷、CCUS、范围三、评级提升 |

### 第 1 步：分层检索（六个方向，缺一不可）

按 `references/source-catalog.md` 的清单，每个方向至少 2 组关键词、跨 2 个信源层级：

1. **国内政策与标准**——财政部可持续披露准则体系、生态环境部、发改委/能源局、交易所自律规则、全国碳市场配额方案
2. **国际规则与标准**——ISSB/IFRS、CSRD/ESRS、CBAM、GRI、SBTi、ISO
3. **评级与指数**——MSCI、S&P CSA、CDP、中证/华证/Wind/商道融绿；重点查"方法论更新"与"评级结果变更"
4. **行业层面**——行业规划、行业标准、行业协会数据、技术路线（CCUS、甲烷、煤电低碳化改造）
5. **客户公司**——公告、季报、官网新闻、投资者关系记录、互动平台问答、获奖与处罚
6. **对标企业**——同业 3–5 家的关键 ESG 动作，只取"可对比"的（同样的议题、同样的指标）

检索技巧：
- 政策类用"发布 + 施行 + 征求意见 + 截止"组合词，抓时间节点
- 评级类用"评级 + 上调/下调 + 方法论/模型版本"
- 公司类用"股票代码 + 公告 / 运营数据 / ESG"
- 行业类用"行业 + 首个 + 试点 + 标准 + 立项"

### 第 2 步：筛选（五条规则，逐条过）

1. **相关性**：与客户的业务、披露义务、评级、成本至少一项直接相关；否则降级到"行业观察"或丢弃。
2. **权威度**：官方原文 > 监管/交易所 > 评级机构/行业协会 > 主流财经媒体 > 自媒体。自媒体只用于发现线索，不作为引用来源。
3. **实质性**：优先"改变规则、改变成本、改变评价"的信息；排除仅表态、仅活动报道。
4. **去重合并**：同一事件多家报道时合并为一条，引用最权威来源，其余作为旁证。
5. **容量控制**：政策 5–8 条、行业 4–6 条、公司 4–6 条、对标 3–5 家。宁少勿滥。

### 第 3 步：建事实卡（内部工作底稿，不进报告正文）

每条信息整理成一行结构化记录，字段固定：

```
事件｜日期｜来源机构｜链接｜类别(政策/评级/行业/公司/对标)｜影响对象｜影响方向(利好/承压/中性)｜影响量级(高/中/低)｜依据数字｜建议动作
```

影响量级判定口径：
- **高**：直接产生合规义务、改变披露口径、影响评级档位、带来可测算成本/收入
- **中**：影响预期与叙事、改变同业基准、需要内部准备但不立即合规
- **低**：背景性、宣示性

### 第 4 步：写影响评估（最容易写空的一节，按此模板）

对客户公司的每条动态，写足四层：

```
【事件】本月发生了什么（客观、含数字）
【对 E/S/G 的影响】分别说明，只写有实际影响的面；无影响的面写"无直接影响"
【与监管/评级的连接】对应哪一条规则、哪个评级维度、哪个指标
【建议动作】动作 + 责任部门 + 时间节点 + 预期效果
```

示例（事件→影响→动作）：
> 收购国能新疆煤制气 50% 股权（6.18 亿元），标的核心资产为准东 20 亿方/年煤制气项目。
> **E 维**：煤制气属高耗能高排放环节，投产后将增加范围一排放与用水强度，改变碳排放总量与强度趋势线；
> **G 维**：关联交易，需在年报关联交易与 ESG 报告中说明定价公允性与治理程序；
> **连接**：财政部《气候准则》要求披露范围一/二/三与资本性支出中的气候相关投入，本项目属"气候相关资本支出"须单列。
> **动作**：财务部 + 安环部在 2027 年预算编制前（2027-02）建立该项目碳排放与用水基线，纳入集团碳数据平台；ESG 报告编写组在 2026 年报"气候相关资本支出"一节补充披露。

### 第 5 步：渲染

```bash
# 生成 md + 单文件 HTML（含目录、KPI 卡片、图表内嵌）
python scripts/build_report.py report.md --html report.html --kpi kpi.json --charts charts.json

# 质检：检查引用编号是否都有对应来源、是否缺日期
python scripts/build_report.py report.md --check
```

报告结构见 `references/report-spec.md`，写作规范见同文件"写作规范"一节。

### 第 6 步：质检（逐条打勾，不合格就改）

见 `references/quality-checklist.md`。至少确认：五条硬性质量线全部满足、结构完整、无"（待补充）"占位符、所有数字可在来源中找到。

## 常见坑

- **把"征求意见稿"写成"已发布"**：务必区分 征求意见 / 发布 / 施行 / 截止 四个状态，写进表格"状态"列。
- **评级数字混用不同口径**：MSCI 是字母档、S&P CSA 是百分制、CDP 是 A–F 档、中证是 AAA–C。不要跨体系比高低，只在同一体系内做同业对比。
- **只搜一个月会漏掉"上月发布、本月截止/施行"的关键节点**：检索时必须同时覆盖统计期前 60 天发布、统计期内生效或截止的政策。
- **上市公司履约承诺类问答（如互动平台）不可当作事实引用**：只能作为"投资者关注点"呈现。
- **行业对标只比结论不比口径**：同业"碳减排 X%"若边界不同（范围一/二 vs 含三），必须标注口径差异，否则结论无效。
