# 关键词矩阵与检索式

> 只搜"ESG"会漏掉大约 80% 的碳类项目。四个簇必须同时覆盖。

## 一、四簇关键词（建议全量使用）

### 簇 A：披露类（高频薄利，企业客户为主）

| 关键词 | 说明 |
| --- | --- |
| ESG | 母词，噪音大但覆盖率最高 |
| ESG报告 / ESG报告编制 | 最精准的采购标的词 |
| 可持续发展报告 | 交易所指引用语，A 股公司主流表述 |
| 社会责任报告 | 国企/城投常用表述 |
| 环境、社会及管治报告 | 港股表述，单价通常更高 |
| ESG咨询 / ESG顾问 | 多年期框架服务 |
| ESG鉴证 / ESG审验 | 2025 年后新增需求，单价高 |
| 环境信息披露 | 金融机构与上市公司 |
| ESG评级 / ESG数据 | 指数公司、数据服务商采购 |

| MRV / 碳排放监测计划审核 | 技术性强，竞争者少 |

## 二、检索式组合技巧

| 目的 | 检索式 |
| --- | --- |
| 找已成交项目 | `关键词 + 中标`、`关键词 + 成交结果`、`关键词 + 结果公告` |
| 找在招项目 | `关键词 + 招标公告`、`关键词 + 竞争性磋商`、`关键词 + 询比` |
| 锁定大额项目 | `关键词 + 万元`、`关键词 + 亿元`（标题常直接写金额） |
| 锁定客户类型 | `关键词 + 央企`、`关键词 + 集团`、`关键词 + 银行` |
| 锁定多年期框架 | `关键词 + 2026-2028`、`关键词 + 三年`、`关键词 + 框架协议` |
| 找平台页面 | `site:` 域名 + 关键词（如 `qianlima.com ESG 中标`） |

## 三、赛道分类优先级（引擎内置）

匹配顺序即优先级，先命中先归属，避免"碳足迹报告"被错分到"ESG 报告"：

```text
碳足迹 → 碳核查/核算 → 碳资产/碳交易 → 转型金融/绿色金融 → 双碳战略/规划
→ ESG评级/数据 → ESG报告/披露 → ESG咨询/顾问 → 绿色供应链/贸易 → 环境合规/生态
```

## 四、每日监控的最小关键词集

全量抓取成本高，日常只需 6 个高频词即可覆盖绝大多数新增：

```text
ESG  碳核查  碳足迹  双碳  碳中和  CBAM
```

周末或周初补一次全量（12—15 个词），可兼顾成本与召回。
