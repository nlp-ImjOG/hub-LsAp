# 数据源清单与可达性实测

> 实测环境：中国境内网络，2026-11-24。表中"可达"指从本机 Python `requests` 直接 GET 能返回 200 且有正文。
> 海外/云服务器访问国内政务站的结论可能不同，换环境需重测。

## 一、实测结果（关键结论先看）

| 数据源 | 地址 | 实测 | 可用性说明 |
|---|---|---|---|
| **203060 双碳文库** | `www.203060.com` | ✅ 200 / 150KB | **首选**。列表页可按关键词检索，**标题自带金额与项目名**（如"【中标】碳核查98.9万：…"）；详情页补发布日期。列表页 GBK 编码，需 `apparent_encoding` |
| **全国招投标绿色公共服务平台** | `greenbid.cn` | ✅ 200 / 19KB | 可抓。公示类记录，**企业名与项目名部分打码、无金额**，只能用于"是否出现新项目"的哨兵用途 |
| **千里马招标网** | `www.qianlima.com` | ✅ 200 / 110KB | 详情页可抓，标题含金额；**正文与中标单位需会员**，金额常以"￥14.38万元"形式出现在标题 |
| **电力能源招标网** | `www.dlnyzb.com` | ⚠️ 429 | 内容质量最高（含成交价、采购单位、资格条件），但**直接抓取易被限流**；经搜索引擎快照/摘要获取更稳 |
| **中国政府采购网** | `search.ccgp.gov.cn` | ❌ 超时 | 80 端口连接超时，https 亦超时。不可作为自动化数据源 |
| **全国公共资源交易平台** | `deal.ggzy.gov.cn` | ❌ DNS 失败 | 域名解析失败（本机 DNS），无法访问 |
| **国资委 / 生态环境部 / 发改委** | `sasac.gov.cn`、`mee.gov.cn` 等 | ⚠️ 部分可达 | 首页多超时或 403，但**具体 PDF 链接常可直接下载**（如 mee.gov.cn 的政策 PDF）。适合"已知 URL 再取正文" |
| **财新 / 第一财经 / 新浪财经** | 各家 | ✅ 200 | 适合做政策解读与背景补充，不作原始数据源 |

## 二、推荐采集组合

**历史基线（一次性）**：203060 双碳文库（广度）+ agent 检索补录（深度，含中标人）
→ 文库站提供"标题即金额"的高性价比样本，agent 检索补充央企平台的成交价与中标人。

**每日监控（增量）**：203060 列表页 `page=1` 增量 + greenbid 哨兵
→ 单个关键词一页约 20 条，覆盖 10 个关键词即约 200 条/日候选，去重后通常新增个位数。

## 三、203060 采集要点

```
https://www.203060.com/plugin.php?ac=list&cate=0-0-0&id=keke_doc&keyword={关键词}&o=3&page={页码}
```

- 页面编码 **GBK**，Python 需 `r.encoding = r.apparent_encoding`，否则中文全部乱码。
- 记录锚点：`<a href="doc-view-{id}.html" class="doc-mod">`，标题文本混有图标字体（私有区字符）、"会员免费下载"、"浏览数/下载数"残渣，必须清洗。
- 详情页可提取"发布时间"，但会混入"截止日期""下一年度"等年份，需限定 `2015 ≤ 年 ≤ 今天`。
- 站内混有白皮书、分析报告、职位报告、名单类文档，必须用 `is_tender()` 过滤。

## 四、扩展数据源（需付费或需授权，未纳入本期）

| 源 | 说明 |
|---|---|
| 中国招标投标公共服务平台 `cebpubservice.com` | 权威原始公告，检索需验证码 |
| 剑鱼标讯 / 比地招标网 / 中国采购与招标网 | 商业聚合，字段全但需会员 |
| 各省公共资源交易中心 | 省级核查大包的原始出处，需逐省适配 |
| 央企电子采购平台（国家能源 e 购、中广核、大唐、国投） | 成交价最准，页面结构各异 |

接入建议：优先买一家商业聚合的 API（千里马/剑鱼），一次性解决"中标人"字段缺失问题——这是当前数据最大短板。

## 五、抓取纪律

- 单站请求间隔 ≥ 1 秒，失败重试 2 次退避，避免被封。
- 不绕过验证码、不破解登录墙；正文需会员的一律标记"未公开"。
- 只采集公开招标/中标公告，不采集个人联系方式。
- 记录保留原文 URL，报告明细必须可回查。
