# 报告结构与写作规范

## 一、标准结构（十节）

| 节 | 内容 | 篇幅建议 |
| --- | --- | --- |
| 报头 | 客户主体、统计期、行业、对标组、出报日 | 1 段 |
| KPI 卡片 | 4 个最能代表现状的数字（含同比与来源编号） | 4 张卡 |
| 一、本月要点 | 5 条判断，每条都要有"所以呢" | 5 条 |
| 二、政策与标准 | 国内 / 国际 / 评级三小节 + 政策日历表 | 3 小节 |
| 三、行业动态 | 行业政策、技术与标准、同业实践 | 2—3 小节 |
| 四、公司动态与影响评估 | 经营动作、外部评价、**影响评估表** | 3 小节 |
| 五、对标企业 | 固定维度的对比表 + 一句结论 | 1 表 |
| 六、下月关注 | 带日期的前瞻清单 + 风险提示 | 4—6 条 |
| 附录 A/B | 评级快照、事件日历 | 2 表 |
| 附录 C/D | 来源清单、方法与免责 | 必需 |

## 二、写作规范（决定报告能不能被读下去）

### 结论先行

每节第一句就是判断，不是背景。反例："随着双碳战略推进，ESG 日益重要……"正例："本月的规则变化集中在'数据能否追溯'，对企业意味着新增两项举证义务。"

### 量化优先

拒绝"大幅""显著""有效提升"。要写"强度由 5.89 升至 6.78 吨/万元，同比 +15.1%"。
**没有数字的判断要标注"（分析）"**，与事实区分。

### 一句一事实 + 引用编号

每条事实末尾加 `[n]`，n 对应附录 C。一段里不要塞三个事实再统一标注，读者无法定位。

### 分层表达

- **事实**：谁在什么时间发布了什么。
- **影响**：对客户的 E/S/G 分别意味着什么。
- **动作**：做什么、谁做、什么时候前完成。

三段缺任何一段，这条信息就不该进正文。

### 表格化的场合

| 场合 | 用表格 |
| --- | --- |
| 时间节点与状态 | 政策日历（时间/事项/状态/与客户关系） |
| 多主体对比 | 对标表（维度 × 公司） |
| 待办与责任 | 影响评估表（事项/影响面/量级/动作/责任与时限） |
| 评级快照 | 机构/评级/时点/同业位置/备注 |

### 视觉元素

- **KPI 卡片**：4 个，每个含数值 + 说明 + 来源编号，用于回答"现在处于什么位置"。
- **时间线**：只用于"事件日历"，按日期排列，每条一行。
- **色块标签**：影响量级用 `<span class="tag high">高</span>`，方向用 `pos/neg`。

## 三、影响评估模板（第四节核心）

对客户公司的每条动态，写足四层：

```text
【事件】本月发生了什么（客观、含数字、带引用）
【对 E/S/G 的影响】分别说明，无影响的面写"无直接影响"
【与监管/评级的连接】对应哪条规则、哪个评级维度、哪个指标
【建议动作】动作 + 责任部门 + 时间节点 + 预期效果
```

填写示例：

> **事件**：收购准东 20 亿立方米/年煤制气项目 50% 股权，交易对价 6.18 亿元，计划 2027 年底投料试车 [23]。
>
> **E 维**：煤制气属高耗能高排放环节，投产后新增范围一排放与用水强度，改变排放总量与强度趋势线。
> **G 维**：关联交易，需在年报关联交易与 ESG 报告中说明定价公允性与决策程序。
> **监管连接**：《气候准则》要求披露范围一/二/三及气候相关资本支出，本项目属"气候相关资本支出"须单列。
>
> **建议动作**：财务部 + 安环部在 2027-02 前建立该项目碳排放与用水基线并接入集团碳数据平台；ESG 报告组在 2026 年报"气候相关资本支出"一节补充披露。

## 四、附录 C 来源表格式（质检脚本依赖）

```text
| 编号 | 机构 | 日期 | 链接 |
| --- | --- | --- | --- |
| 1 | 财政部《…规划》 | 2026-11-11 | [链接](https://…) |
```

要求：编号连续、日期为 `YYYY-MM-DD`、链接可点。`build_report.py --check` 会校验正文引用与来源表是否一一对应。

## 五、可直接使用的 HTML 组件

报告由 `build_report.py` 渲染，正文中可直接嵌入以下 HTML（脚本原样输出）：

```html
<!-- KPI 卡片 -->
<div class="kpis">
<div class="kpi"><div class="v">19,982</div><div class="l">说明文字</div><div class="d">来源 [30]</div></div>
</div>

<!-- 时间线 -->
<div class="tl">
<div class="ev"><div class="d">2026-11-18</div><div class="t">事件描述 [15]</div></div>
</div>

<!-- 标签 -->
<span class="tag high">高</span><span class="tag neg">合规</span>

<!-- 提示条 -->
<div class="note">需要强调的口径说明</div>
```

## 六、篇幅控制

一页 A4 约容纳 900—1,000 中文字。月报正文建议 6—9 页（含表格与图），附录另计。
超出 12 页说明筛选没做好——把次要信息移到附录或删除。
