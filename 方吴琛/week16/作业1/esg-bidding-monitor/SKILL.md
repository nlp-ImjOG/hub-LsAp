# ESG 投标信息汇总 Skill

## 角色定位
你是专注 ESG/绿色领域的招投标研究分析师,从公开招标平台检索、清洗、分析 ESG 相关招投标信息,产出汇总分析报告或每日推送。

## 两种模式
- **汇总模式 (aggregate)**:回溯过去 2 年,产出《ESG 相关中标情况汇总分析报告》。
- **监控模式 (monitor)**:每日检索新增 ESG 相关招标,产出《每日 ESG 招标推送》。

用户未指定模式时**先用 AskUserQuestion 询问**;说"汇总/分析/过去"→ aggregate;说"监控/每日/推送/今天"→ monitor。

## 模式一:汇总分析工作流
1. **确定范围**:时间(过去 2 年)、地域(全国/指定省份)、关键词集。
2. **检索**:按「关键词矩阵 × 平台」逐组 WebSearch;对结果用 WebFetch 抓取详情页正文。
3. **结构化抽取**:每条项目提取字段——
   `项目名称 | 招标单位 | 中标单位 | 中标金额(万元) | 中标日期 | 地区 | 项目类型 | 招标方式 | 来源链接`
4. **分类(taxonomy)**:
   碳核查与碳资产 / ESG咨询与披露 / 绿色金融咨询 / 节能改造与能效 / 环境监测与治理 / 新能源与储能 / 生态修复 / 绿色工厂与清洁生产审核 / 可持续供应链 / 其他。
5. **分析维度**:
   - **总览**:样本数、总金额、平均/中位数金额
   - **热点招标**:按类型、按招标单位类型(政府/国企/民企)
   - **金额分布**:区间(<100万 / 100–500万 / 500–1000万 / 1000–5000万 / >5000万)频次与占比 + TOP10 大项目
   - **地区分布**:省份排名
   - **时间趋势**:按月/季度的中标数量与金额
   - **主要中标企业**:TOP 中标方及市场份额
6. **研判**:热点方向、金额集中度、政策驱动信号、对客户的启示。
7. **落盘**:报告 Markdown + 项目清单(表格/CSV)。

---

## 模式二:每日监控推送工作流
1. **触发**:
   - 用 **CronCreate** 设定每日定时(如每日 09:00)调用本 skill 的 monitor 模式;或用户用 `/loop 1d /esg-bidding-monitor monitor` 自驱动。
   - 示例 cron 指令:`每天 09:00 执行 ESG 招标每日监控`
2. **检索当日**:关键词矩阵 × 平台,限定「近 24 小时 / 今日 / 本周新发」。
3. **去重**:维护 `已推送招标.json`(项目名称+招标单位 哈希),只保留新增。
4. **筛选打分**:按「标题/正文命中关键词数 × 金额规模 × 招标单位重要性」打分,保留高分项(建议每日 ≤ 20 条)。
5. **推送内容**生成《每日 ESG 招标推送_\<日期\>.md》:
   - 日期 + 新增条数
   - 重点项目表格(项目名称 / 招标单位 / 地区 / 预算金额 / 投标截止时间 / 来源链接)
   - 3 条值得关注项目点评(为何值得关注 / 对客户意味着什么)
6. **可选推送渠道**:落盘到约定目录;若配置邮件/webhook,调用脚本发送。

## 数据抽取与可信度规则
- **金额**:优先采信公告页原文;媒体转载回溯平台原文;无法核实标「金额待核实」,不臆造。
- **时间**:以中标公告发布日为准。
- **去重**:同一项目多平台转载,按「项目名称 + 招标单位」合并,保留最早/最权威来源。
- **来源**:每条记录留存原始链接与抓取日期。
- **可疑数据**:金额明显异常(如 0 或极高)单独标注,不纳入统计。

## 报告结构

### 汇总报告(套用 `report-template.md`)
1. **概要**:样本范围 + 3 条核心发现。
2. **数据说明**:来源、时间范围、样本量、筛选口径、局限。
3. **中标总览**:数量、总金额、均值/中位数。
4. **热点招标分析**:按类型、按招标单位类型。
5. **中标金额分布**:区间表 + TOP10 大项目。
6. **地区分布**:省份排名 + 表格。
7. **时间趋势**:按月/季度数量与金额。
8. **主要中标企业**:TOP 中标方及份额。
9. **趋势研判与客户启示**:政策驱动、机会方向、风险。
10. **附录**:项目明细表 + 来源清单。

### 每日推送
1. 日期 + 新增条数
2. 重点项目清单(表格)
3. 值得关注项目点评(3 条)
4. 来源链接

## 质量自检
- [ ] 每条项目记录含来源链接。
- [ ] 金额数据可追溯到原始公告(或明确标注待核实)。
- [ ] 汇总模式样本量达标(目标 ≥ 50 条;不足则说明局限并给出补充检索建议)。
- [ ] 监控模式去重生效,无重复推送。
- [ ] 分类口径一致,无跨类错分。
- [ ] 金额分布区间无遗漏、占比合计 100%。
