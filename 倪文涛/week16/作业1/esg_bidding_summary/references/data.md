# 数据、去重与金额口径

## 数据文件

`records.json` 是对象数组，每项是一个采购轮次中一个独立包件的**当前核验快照**。公告事件、旧值和证据保留在 `events.jsonl`，搜索与排除项另存日志。每个转载或阶段公告不是独立交易。

结构化明细使用以下字段（英文键，中文值除枚举外可自由填写）：

| 字段 | 含义 |
| --- | --- |
| record_id / project_key | 包件稳定唯一键 / 跨包项目键；二者非空 |
| title / buyer / suppliers | 标题、采购人、最终供应商数组；联合体数组包含全体成员 |
| status | `intent`、`open`、`candidate`、`awarded`、`cancelled`、`failed`、`unknown`；合同公告是证据事件，不单建交易 |
| verification | `primary` 已核验官方或受托代理原文；`secondary` 二手；`unverified` 摘要/不可访问 |
| scope | `core` 核心咨询/研究/鉴证等服务；`extended` 明确相关技术工程设备；`excluded` 范围外 |
| category / tags | 单一主分类 / 次级主题数组 |
| province / industry | 项目或履约地省份 / 采购人所属行业；无法确定写“未披露” |
| award_date | 最终中标/成交公告发布日期，ISO日期；非最终结果可为 null |
| amount_type | `total` 已披露最终成交总价；`unit_price`、`rate`、`ceiling`、`undisclosed`、`mixed` 单列 |
| award_amount_yuan / currency | 最终成交金额的十进制字符串（元）或 null / `CNY` 等币种代码 |
| tax_basis | `inclusive`、`exclusive`、`unspecified`；优先同一公告中的含税成交金额 |
| source_url / evidence | 主证据直达链接 / 关键事实短摘录或准确转述及页码、表行、章节定位 |

每项还应按公告填写：项目编号、包号、采购轮次、代理、公告标题及发布日期、首次发现/最后核验时间、事件列表与链接、采购方式、采购内容及交付物、相关性依据、履约期限、原币原单位原金额文本、预算和限价的独立字段、税口径说明、报名开始/结束时间、文件获取截止时间、投标截止时间、开标时间、资格条件/同类业绩/联合体限制、报名入口及方式、更正关系、证据质量问题。未知为 null 或“未披露”，不要推测补齐。

金额原文数字/单位和规范化数值同时保存；带日期的时刻使用 `+08:00`。只有日期无时刻时保留日期精度，不擅自补成23:59；临近截止按“当日时间待核验”处理。保留原文时区，展示再转换。

`award_amount_yuan` 仅存人民币最终成交总价；外币原价、预算、限价、单价、费率等保存在 `original_amount` 或对应独立字段，该字段保持 null。未披露总价时 amount_type 用 undisclosed；非最终公告的 suppliers 为空数组，候选人另存 candidate_suppliers。最终供应商未披露也用空数组，不虚构名称。一个预算与限价相同的招标公告仍不能填入最终成交金额。

## 去重与事件链

- 优先采用“采购人规范名称＋项目编号＋采购轮次＋包号”作为键。编号不一定全球唯一；标题服务年度不是采购轮次，二次招标不能与首次流标事件混淆。
- 无编号时用采购人、标题核心内容、履约期间、包件与公告日期人工对照；模糊匹配只提示候选，不能仅凭相似标题自动合并。
- 同一采购轮次的招标→候选→最终结果→合同→更正形成事件链；采用截至本次时点仍有效的结果。取消/撤销中标则移出有效金额统计，保留原事件。
- 更正可修改金额、供应商、截止时间，但不删除旧证据。候选公示期已过不会自动变成最终中标。标题写结果、正文仍推荐候选人时，以正文语义判为 candidate 并继续找最终结果。
- 一项目多包分别记交易；总项目只作为 project_key 汇总，不额外计金额。只有总价且无法分包时建“项目总额”单条，不能再录无法对应的子包价。同一包联合体总额只计一次，不为每成员重复计数或分配未经披露的份额。

## 金额

- 1万元 = 10000元；1亿元 = 100000000元。十进制计算，不用二进制浮点累加金额。
- 中标金额来自最终结果或明确确认中标事实的正式文件；预算、限价、报价、代理费、保证金、年度计划与履约支付额不能替代。合同价不同于中标价则单独保存，不悄悄覆盖中标价。
- 费率、折扣、单价、框架上限、预计规模、不确定数量、未披露或混合不可拆价进入项目数量统计，不加入可比总价分布。区间报价不得取中点，多年合同金额不擅自年化。
- 同时有含/不含税时选含税金额并保留另一值；税率未知不换算。总体数字是“按原文已披露人民币总价口径合计”，同时呈现税口径分组，不能称为统一含税规模。
- 外币按币种另表，不默认换汇；用户要求时另存汇率日期、来源和折算结果，不覆盖原值。主金额统计仅使用人民币，记录非人民币排除数。
- 显式0元可保留并核验原因；空白不等于0。异常大/小金额回看单位、附件和包层级，不自动删除离群点。

## 统计前检查与筛选

统计前检查重复ID、必要字段、ISO日期、状态/范围/金额/税口径的取值、币种及非负有限金额。先核验原文与单位、合并同一包件的重复记录，再计算。只能依据证据修正数据，不要为补齐字段填假值；无法确认的记录单列待核验。

主统计仅取窗口内 `status=awarded`、`verification=primary`、scope 为 core/extended 的记录。数量含未披露金额项目，金额仅取 `amount_type=total` 且已披露的 CNY 记录。核心/延伸分组，不混成咨询价格。输出包数、项目数、金额可用率、总额、均值、中位数、P25/P75、范围、金额分档、月/季度、主分类、地区、行业、采购人及联合体整体的分组统计；附样本量与排除理由。
