# 联网检索与自主筛选

## 主题与分类

每个包件一个主分类，按主要交付物归类；其余主题作标签，避免份额重复计算。

| 主分类 | 可组合使用的检索词与采购内容 |
| --- | --- |
| ESG披露与管理 | ESG、环境社会治理、环境社会及治理、可持续发展报告、社会责任报告、ESG管理体系、ESG评级提升、可持续信息披露、报告鉴证 |
| 碳盘查与核查 | 温室气体、碳排放核算、碳盘查、碳核查、范围一/二/三、组织碳核算 |
| 产品碳足迹 | 产品碳足迹、LCA、生命周期评价、EPD、碳标签、碳足迹认证 |
| 双碳规划与转型 | 双碳、碳达峰、碳中和、低碳发展规划、气候风险、转型计划、零碳园区/工厂咨询 |
| 碳资产与市场 | 碳资产、CCER、碳交易咨询、碳配额管理、减排量开发、碳中和认证 |
| 绿色金融与供应链 | 绿色金融评价、绿色债券认证、可持续金融、绿色供应链、供应链ESG尽调 |
| 能碳数字化 | 碳管理平台、能碳管理、碳排放监测、碳数据平台、ESG数据系统 |
| 相关技术工程设备 | 采购内容明确包含上述目标的低碳改造、碳监测设备、零碳园区建设、减排工程 |

纯新闻、政策发布、年度报告下载、招聘、培训宣传不是招采。泛环保保洁、园林、污水处理、常规光伏/风电/EPC、节能设备与煤炭/活性炭等，不因词汇命中自动纳入；范围明确采购双碳成果时进入延伸层并写出依据。相关培训采购可进对应核心主题；碳信用/配额直接买卖默认作附录线索，不加入服务/工程金额。无法拆分的大工程只有局部相关时标明“混合且无法分摊”，不得把整个工程金额解释为ESG服务金额。

## 来源梯队

每次运行检查可访问性，不依赖永久有效的端点或固定 DOM。

1. 官方政府采购、全国/地方公共资源交易、采购人官网、企业官方采购平台；例如 [中国政府采购网](https://www.ccgp.gov.cn/)、[全国公共资源交易平台](https://www.ggzy.gov.cn/)、[中国招标投标公共服务平台](https://www.cebpubservice.com/)。项目可能在地方站、银行、上市公司或央国企平台而未被全国门户收录，应按采购人回查。
2. 公告明确列出的受托采购代理网站及指定发布平台；认定授权应有采购人、代理关系或公告发布媒介依据，不能仅凭商业站点名称。
3. 商业聚合站与供应商新闻用于发现关键词、项目编号、采购人和原文入口；只有转载正文时标注“二手待核验”，不进入最终金额主表。不同聚合站转同一公告不算独立证据。

原文访问受限时尝试采购人官网、指定的另一发布媒介或公开附件。仍不可读取则登记候选信息和受限原因；不要绕过登录/付费或编造原文，相关覆盖标记为不完整。

## 历史搜索策略

1. 把两年窗口切成季度区间，首尾保留实际边界；滚动两年可能涉及九个日历季度。用三组主主题（ESG/可持续报告、双碳/核算/足迹、绿色金融/供应链/能碳平台）分别跨期检索，再补足上表细分类目及延伸层。
2. 每组组合 `中标公告 / 成交公告 / 采购结果 / 中选结果 / 中标候选人`；增加 `site:`、年份/季度词、地区、重点采购人，分批执行独立搜索。不要假定搜索引擎完整支持布尔语法；结果偏少时拆词。
3. 例：`site:ccgp.gov.cn "碳足迹" "中标" 2025`、`"可持续发展报告" "成交" 2026`、`"ESG" "采购结果" 银行`。时间过滤只作召回辅助，入窗看原文公告日期，不看搜索索引日期或标题中的服务年度。
4. 从结果反向扩展采购人、代理、供应商、项目编号与同义词，寻找更早采购公告、后续最终结果和更正。金额极大、多包、标题/正文阶段矛盾的记录优先核验。
5. 每个时间段与主题组至少有可审计的检索记录；薄弱领域改词、换站或地方来源补搜。全国覆盖同时说明实际触达的省份、行业和来源类型，未检出不等于没有采购。
6. 基础矩阵和重点记录核验完成，且连续两轮有针对性的补搜主要返回重复或不相关记录时可以结束，记录停止依据。不能“找到十条就结束”，也不声称全网穷尽。因时间/工具限制提前结束则标记阶段性报告，保存未完成矩阵。

## 每日搜索策略

使用同一主题库，替换阶段词为 `招标公告 / 采购公告 / 竞争性磋商 / 询比 / 比选 / 征集 / 资格预审 / 更正 / 延期 / 终止 / 采购意向`。每天扫所有核心主题与已跟踪采购源；延伸层按已选范围执行。地区/行业可轮换补搜，但日志明确当天覆盖，每周检查整个主题/来源清单有无长期空白。

不能仅搜索“过去24小时”：回看重叠窗口以捕获迟索引与更正，并直接检查重点采购门户。新发现旧公告标为“补录”；是否仍能报名另行判断。

## 检索日志

保存 `search-log.jsonl`，每条包含运行ID、执行时间、主题/地区/期间、查询词、来源域名、访问结果、候选数、确认数、重复数、排除数及原因、失败原因和后续动作。禁止填未执行的查询。报告给出覆盖表和漏检风险，不能把搜索结果估算条数作为项目数。
