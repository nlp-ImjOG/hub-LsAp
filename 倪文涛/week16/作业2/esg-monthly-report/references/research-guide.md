# 检索、证据与筛选指南

## 从客户议题出发

查截至信息截止日最新可用的年报、可持续发展报告、官网业务与投资者关系资料；历史资料用于画像，不自动算本期新闻。历史月报的客户业务、同行选择和方法版本也应按当时已知信息确定，避免把今天的情况倒推到过去。初步议题是研究假设，除非有正式评估依据，否则不要称为客户已批准的重要性评估。

| 业务特征 | 优先检索议题（按业务调整） |
|---|---|
| 制造、能源、化工、采矿 | 能源与排放、排污、水、职业安全、供应链、人权、社区与生态 |
| 汽车、电池、电子 | 产品安全、原材料追溯、供应链劳动、碳足迹、回收、数据安全 |
| 金融 | 投融资相关影响、客户保护、数据隐私、商业道德、气候风险治理 |
| 消费、食品、农业 | 质量与召回、采购追溯、土地与森林、水、包装、员工及供应商劳动 |
| 互联网、软件、服务 | 隐私与网络安全、AI 治理、员工、供应商、能耗、商业道德 |
| 地产、建筑、物流 | 建筑与运营能耗、工地与运输安全、外包劳动、气候韧性、供应链 |

按“客户／同行 × 议题 × 地区 × 时间”建立小型检索矩阵，覆盖业务暴露即可，不做无差别全球汇编。检索不要只用“ESG”：污染、工伤、召回、处罚和治理新闻常不带这个标签。

## 搜索与阅读

1. **定向发现**：官方站内搜索或搜索引擎 `site:`，结合全称／证券代码／英文名、月份与议题。
2. **扩展发现**：行业协会、可信新闻媒体与专业机构用于发现遗漏、争议和实践；国际业务补充英文或当地语言。
3. **原文核实**：追到法规全文、公告、评级机构、公司发布或原始采访。阅读关键附件，数字与适用条款核到章节。无法读正文的消息留作线索，说明限制。
4. **反向核验**：负面指控查监管／司法进展、公司回应与更正；重大利好查结果是否只是承诺、有无范围与基线。
5. **补缺**：检查政策、评级、标准、行业、客户、同行及重要 S／G 议题是否查过。无结果时换名称、议题或来源再查，不把首次零结果当结论。

查询例式（替换变量）：

- `公司全称／证券代码 + 处罚／事故／召回／劳动／数据泄露／董事会 + 月份`
- `公司英文名 + sustainability / supplier / safety / investigation + month year`
- `行业 + 经营地 + 政策／征求意见／披露／标准 + 月份`
- `评级机构 + methodology / consultation / issuer rating + month year`
- `同行名称 + 项目／采购／循环利用／职业健康／治理 + 月份`

时间过滤只用于发现，不代替正文日期。可检索相邻月份来确定事件、披露和生效时间；最终按确定的期间口径筛选。

底层法规全文或方法附件受限，但已读到发布机构的官方说明时，可引用该说明确实支持的事实，并明确附件未核实；不得据此推断说明未载明的条款、技术变化、生效日期或具体客户适用性。搜索结果摘要不属于这种替代证据。

## 来源路线图

以下是发现路径，不是永久有效的规则或当期事实。每次确认官网、文件及适用版本；引用具体文件页面，不能用主页证明细节。

| 类别 | 优先路径 | 使用边界 |
|---|---|---|
| 中国政策监管 | 中国政府网、财政部、生态环境部、证监会、行业主管部门、地方部门及处罚公示 | 读正文及附件；区分表态、通知、规范与执法决定 |
| 上市披露 | 上交所、深交所、北交所、港交所或其他上市地交易所 | 核对市场、主体、指数／门槛和期间；指引与编制指南不同 |
| 国际标准采纳 | IFRS／ISSB、GRI、行业准则制定机构及当地监管部门 | 国际准则与当地采纳分开，核实适用版本 |
| 欧洲规则 | 欧盟委员会、EUR-Lex、国家主管部门；EFRAG 技术材料 | 技术建议、草案和法律分开；核实延后、修订及门槛 |
| 气候自然目标 | GHG Protocol、SBTi、TNFD 等原始发布和公开数据库 | 承诺、提交、验证、达成状态不同，框架用途不同 |
| 评级问卷 | MSCI、Sustainalytics、S&P Global CSA、CDP、EcoVadis 等公开文件或授权资料 | 不假定个体评级免费；不绕过付费或授权限制 |
| 客户同行 | 交易所公告、投资者关系、正式报告、新闻稿、监管司法文件 | 公司自述证明其作出声明，不独立证明成效或领先 |
| 行业事件实践 | 原始材料、协会、可信专业媒体及研究机构 | 协会评优、广告和转载不等于独立验证 |

以下原始入口可参考；每次确认版本，不把旧事件当本期动态：

- [IFRS：按司法辖区查询准则使用情况](https://www.ifrs.org/ifrs-sustainability-disclosure-standards-around-the-world/use-by-jurisdiction/)：发现采纳路线，再读当地正式要求。
- [上交所：第 14 号可持续发展报告指引页面](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/mainipo/c/c_20250516_10779150.shtml)：核对正式文件、附件及发布／生效日期的路径。
- [MSCI ESG Ratings 方法文件入口](https://www.msci.com/documents/1296102/34424357/MSCI%2BESG%2BRatings%2BMethodology.pdf)：可能重定向新版本；历史报告须另找当时版本。

## 日期与版本

区分**事件发生日、首次公开披露日、网页更新日、生效／截止日**；实际检索日另记。

- 本期发生且截止日前已公开：可入选。
- 本期首次披露旧事项：标“本期披露／事件发生于某日”，不可改写成当月发生。
- 旧文件本期生效或到关键期限：可作“本期生效／期限提醒”，明确原发布日期。
- 本期发布年报／ESG 报告：发布是本期事件，内含的过往绩效是历史数据。
- 仅本期更新网页或转载，没有实质新增：排除本期动态，可作标年的背景。
- 截止日后才首次披露：不纳入当时信息口径；用户要求事后复盘时单列期后事项。
- 无日期：查官方列表、文件、公告或可核实的存档；不从网址或抓取时间直接推定。仍不明确则观察或作背景。

## 轻量证据台账

实质候选事件按 E01、E02 编号，多来源合并，不要求保存全部无关搜索结果。CSV 用 UTF-8，按标准转义逗号、换行和引号。每行一个候选事件：

| 字段组 | 内容 |
|---|---|
| 身份 | ID、类别（政策／评级／标准／行业／客户／同行）、标题、主体及关联公司 |
| 时点 | 事件日、披露日、生效／截止日（适用时）、本期入选依据 |
| 来源 | 发布方、原文标题、URL、访问日、关键页码／章节或短摘录、多来源关联 |
| 证据 | 已读／仅摘要／受限、官方／公司自述／独立报道、能支持的具体事实、冲突与限制 |
| 判断 | E／S／G 议题、客户关联、影响与紧迫性、采纳／观察／排除及理由、正文位置 |

来源多可在单元格以分号分隔并对应标题。摘录只留核验所需短句，遵守版权限制，不保存整篇新闻。无法确认填“未披露／待核实／不适用”，不猜测。

简短检索记录包括：实际查询、检索日期、所查客户／同行／机构与期间、访问失败、未覆盖议题和原因。只记真实过程，不补造。

## 筛选与停止

先过四个门槛：主体可信、期间成立、证据足以支撑事实、具体 ESG 关联。再定性筛选：

- **优先深入**：直接适用且临近的义务、重大事故／处罚／争议、显著客户风险机会、改变竞争条件的已验证实践。
- **择优入选**：间接相关政策信号、有迁移机制的行业行动、需提前准备的标准或评价变化。
- **观察／排除**：纯宣传奖项、重复、未核实指控、无日期消息、无客户关联的宏观新闻。

高潜在影响但证据弱的线索应补证；未核实则放观察事项并说明，不写成事实也不悄悄丢失。一份权威原文可能比多篇同源转载可靠。

覆盖路径已查、重大日期与适用性已核实，且补充检索不再发现能改变结论的新信息时停止。不为凑数量无限搜索；受工具或时间限制时交代未完成范围，不称全面覆盖。

## 影响分析边界

- 分别写“公告披露……”与“潜在影响为……，条件为……”。不将推断冒充来源结论。
- 比指标前核实组织范围、期间、单位、产量分母、排放范围、基准年、方法、绿电／抵消处理、重述。不可比则比较措施成熟度，不做排行榜。
- 原文数字也要做合理性检查：核对单位、基数、百分比变化与百分点、数值范围及计算关系。遇到无法解释的异常值，回查附件或其他来源；仍不清楚则不用于量化结论，说明原文口径待核实，不能静默修正或照抄成效。
- 强度下降不等于绝对排放下降；目标验证不等于达成；绿色融资用途承诺不等于已产生环境效益。
- 争议区分指控、调查、裁决、整改，说明来源及公司回应。冲突无法解决时展示差异与不确定性。
- 缺少披露不等于违法、缺少管理或必然降级；内部暴露和能力不明时列为待核实输入。
