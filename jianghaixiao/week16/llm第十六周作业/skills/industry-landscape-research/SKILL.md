# 目标

围绕一个产业主题，收集政策、公司公告、论文、行业报告、新闻和产业链信息，识别关键玩家、驱动因素、瓶颈、时间线和不确定性。

# 工作流程

1. 明确行业范围、地域范围和时间窗口。
2. 从政策、技术、需求、供给、资本和竞争六个维度拆解问题。
3. 收集一手资料，优先使用政府文件、公司公告、论文和权威行业报告。
4. 为核心判断建立证据表，记录来源、时间、观点和置信度。
5. 识别不同来源之间的矛盾，单独列出“争议点”。
6. 输出产业链地图、关键玩家、驱动因素、商业化瓶颈和三种情景预测。
7. 给出未来 12—18 个月的观察指标和决策建议。

# 输出格式

- 执行摘要
- 行业边界与研究口径
- 产业链与关键玩家
- 技术与商业化进展
- 驱动因素
- 主要瓶颈
- 三种情景预测
- 风险与反面证据
- 观察指标
- 来源列表

# 质量要求

- 区分“已发生事实”“公司目标”和“分析预测”。
- 对预测给出时间范围和条件，不使用无条件确定语气。
- 对关键判断标注高、中、低置信度。
- 对利益相关方来源，例如厂商官网，必须注明立场。

# 脚本

- `scripts/collect_sources.py`：整理搜索候选结果。
- `scripts/build_evidence_ledger.py`：生成证据账本。
- `scripts/validate_report.py`：检查引用和报告结构。
