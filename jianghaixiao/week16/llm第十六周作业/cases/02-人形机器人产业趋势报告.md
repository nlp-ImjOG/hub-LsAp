# 案例报告 2：人形机器人产业趋势与商业化

## 1. 结论摘要

人形机器人正处于“技术验证向小规模商业化过渡”的阶段。未来 12—18 个月，优先落地场景更可能是工厂、物流、危险作业和展示服务，而不是家庭通用机器人。

## 2. 产业驱动因素

- 劳动力短缺和人工成本上升。
- 大模型提升任务理解和人机交互能力。
- 执行器、传感器和电池成本逐步下降。
- 政策支持和制造业自动化需求。
- 资本对具身智能赛道的持续关注。

## 3. 主要瓶颈

| 瓶颈 | 影响 |
|---|---|
| 灵巧操作能力不足 | 难以完成复杂装配和家庭任务 |
| 续航和散热 | 限制连续工作时间 |
| 可靠性和维护成本 | 影响规模化部署 |
| 成本过高 | 投资回收周期长 |
| 安全与责任界定 | 限制人机协作场景 |
| 数据不足 | 泛化能力有限 |

## 4. 竞争格局

主要参与者可以分为三类：

1. 整机厂商：Tesla、Figure、Boston Dynamics、Unitree、UBTech 等。
2. 核心零部件厂商：减速器、丝杠、电机、传感器、灵巧手等。
3. 软件与具身智能平台：负责感知、决策、控制和数据闭环。

短期竞争焦点不是“谁更像人”，而是：

- 能否稳定完成特定任务。
- 单台成本能否下降。
- 维护是否简单。
- 是否具备真实客户和复购。

## 5. 情景预测

| 情景 | 时间 | 主要特征 |
|---|---|---|
| 保守情景 | 2026—2027 | 工厂和物流小批量试点，家庭场景有限 |
| 基准情景 | 2028—2030 | 特定垂直场景规模化，核心零部件先受益 |
| 乐观情景 | 2030 年以后 | 成本、可靠性和泛化能力同时突破，进入更广泛服务场景 |

## 6. 决策建议

- 关注已有真实订单和试点案例的整机厂商。
- 优先研究价值量高、技术壁垒高的核心零部件。
- 不只看演示视频，要跟踪连续工作时间、故障率、维护成本和客户复购。
- 对“家庭通用机器人”保持长期关注，但短期不宜高估商业化速度。

## 7. 风险与不确定性

- 厂商宣传和实际交付之间存在差距。
- 行业标准和安全法规尚不成熟。
- 技术路线可能发生变化。
- 资本市场情绪可能放大短期波动。

## 8. 研究来源类型

- 政府产业政策和制造业规划。
- 公司公告、财报和产品发布会。
- 学术论文和机器人会议资料。
- 行业协会和咨询机构报告。
- 主流媒体和产业链访谈。
