# 作业 1：构建两个 Skill 并完成两个案例

## 一、Skill 1：tech-selection-research

- 目录：`skills/tech-selection-research/SKILL.md`
- 用途：技术产品、开源框架和开发工具的联网检索、来源筛选、指标对比与选型建议。
- 核心流程：明确问题 → 生成检索矩阵 → 收集原始来源 → 建立对比矩阵 → 交叉验证 → 输出报告。
- 适用案例：AI Agent 开发框架选型。

## 二、Skill 2：industry-landscape-research

- 目录：`skills/industry-landscape-research/SKILL.md`
- 用途：技术、产业或市场主题的联网检索、来源筛选、趋势分析和情景预测。
- 核心流程：明确行业边界 → 收集政策/公司/论文/新闻 → 建立证据表 → 识别矛盾 → 输出情景预测和观察指标。
- 适用案例：人形机器人产业趋势与商业化。

## 三、两个 Skill 的共同设计原则

1. 自主搜索互联网，但不能把搜索摘要当作证据。
2. 优先使用官方文档、原始数据、论文、公司公告和权威报告。
3. 关键判断必须能追溯到来源，并标注置信度。
4. 单独记录反面证据、矛盾信息和资料不足。
5. 区分事实、厂商目标和分析预测。
6. 最终报告必须包含摘要、方法、发现、风险、建议和来源。

结论：人形机器人正处于技术验证向小规模商业化过渡阶段。未来 12—18 个月优先落地工厂、物流、危险作业和展示服务；家庭通用机器人仍需更长时间。
